## 0. 一句话世界

> 一个**没有魔神**的西幻大陆。天地的底质是**以太**，生灵以**精神力**驭以太而施法、以**生命力**炼肉身而战斗——这两套体系**自世界初开便已存在**。**魔法要看天赋，斗气人人可得。**
> 太古盛世原有**八道本源**。万古以来最强的凡人、六阶准神**卢西恩·凯德**，一生所求只是超越那个被光明选中的师弟；他深入堕落半岛，**第一个主动吸收了黑暗以太**——于是**世界为回应他，凝聚出第九枚徽记**。
> 他成了第一位黑暗半神「**蚀主**」，绵延近千年的**大寂灭之战**就此爆发。那一代九位半神**只活下来两个**：**龙神与风神**——其余七位，一位归寂、一位自碎其印、五位战死，**包括他本人**。
> **而他不是被封印的，他是被杀死的。** 众神围攻近千年，只为创造那么一个瞬间，让一个连名字都没留下的**人类士兵**刺出最后一击。三万年来所有人都以为他被封在异次元——**封在那里的，只是一枚没有主人的徽记。**
> 如今徽记在呼吸、以太潮汐再度逼近，**四座神位空悬**，而世上唯一被锁起来的光明徽记——**它不会选择教会想要的那个人。**

## 1. 世界底质

### 1.1 以太 · 世界的底质【补】
**以太（Ether）** 是世界初开时便存在的底质与介质：万物由以太凝聚成形，万物之间亦充溢以太。

- **一切魔法，都是以精神力塑形以太的技艺。**
- 以太带有**属性倾向**：**风、火、水、土为四大基础属性**；雷霆、寒冰、熔岩、金属、雾、潮汐皆为四者的衍生或复合。
- **自然以太**：受世界法则约束，稳定、可塑。
- **黑暗以太**：位面壁垒之外的"**虚空**"中沉积的、**从未被世界法则驯化的原始以太**。与自然以太**同源异态**——它不是另一种物质，而是"**没有秩序的以太**"。

> 所以「净化」在物理上是可能的：圣光做的不是消灭，而是**令扭曲的以太回归秩序**。

### 1.2 黑暗以太的侵蚀机理 · 与「意志」的重要性【修订】

**物理层**：它强行改写所接触之物的**形态**。

| 对象 | 后果 |
|---|---|
| **野兽** | 形态被改写 → 畸变、狂化、等级跃升，最高被强推入**本源期**成为**伪半神巨兽** |
| **土地与器物** | 以太沉积 → 腐化地带、遗迹异变、封存之物的封印失效 |
| **智慧种族** | **先改写精神与自我，再改写身体** |

**精神层**

> **黑暗以太侵蚀的入口，是「意志的缺口」。**
> 它不攻击强度，它攻击**不坚定**。一个人只要还没想清楚自己为什么活着，它就有一根可以撬动的杠杆。

两条推论，解释了这个世界最关键的一些现象：

1. **信仰坚定者极难被侵蚀。** 这就是**圣光教会能对抗黑暗意志的根本原因**——他们的信仰非常坚定，他们信仰光明。同样，精灵的数万年守序、矮人的契约信条、兽人的先祖图腾，都是天然的甲。
2. **主动吸收是另一回事。** 明知会堕落却仍去换取力量的人，会**真的变强**——这不是被骗，这是**交易**。

**于是这个世界有两层防御：**

| 层 | 手段 | 作用 |
|---|---|---|
| **物理层 / 净质** | **圣光魔法** | 清除**已经进入体内**的扭曲以太（百分百特攻）。治的是"病" |
| **精神层 / 抗侵** | **意志与信仰** | 阻止侵蚀的**第一步**。它不是法术，是人格。治的是"门" |

> **一句可以用在故事里的话：** 圣光能把你身上的黑暗烧干净，但只有你自己能决定它进不进来。

## 2. 力量体系

### 2.1 两股内在之力 · 相消律
| | **精神力**（Mind） | **生命力**（血气 / Vitality） |
|---|---|---|
| 方向 | **向外**：作用于体外的以太 | **向内**：作用于自身肉体与意志 |
| 显化 | **魔法** | **斗气** |
| 天赋顶点 | **精灵** | **兽人** |
| 代价 | 精神愈盛，肉身愈脆 | 血气愈盛，神魂愈钝 |

**相消律**：两系同修在凡俗种族中极其困难。**龙族血脉"精神与肉身未曾分化"，是唯一天生无相消的种族**；**人类两系皆平庸却皆不残**，是唯一能勉强并修者——这才是"枢纽种族"真正的底牌。

### 2.2 魔法六系
| 流派 | 原理 | 主宰者 |
|---|---|---|
| **元素系** | 驱动四大基础属性及其衍生以太 | 人类法师、龙族 |
| **生命系** | 以以太作用于**生命形态**：修形（修复肉身、续接筋骨） | **精灵**（独尊） |
| **圣光系** | **净质**：令扭曲以太回归自然以太 | 圣光圣庭国 |
| **黑暗系** | 令自然以太**扭曲**（全大陆禁绝） | 堕落半岛 |
| **符文与锻附** | **以太赋形**：把以太**固化**进物质——<b>但矮人造不出会运转的「回路」</b>，可运转的法阵是**人类的天才**造的 | **矮人**（固化）＋ **人类**（回路） |
| **潮汐系** | 深海以太的独有运作 | 海裔 |

**两大治愈体系互补，以及它们互相看不起的原因**
- **生命魔法修"形"**，无法清除体内的黑暗以太 → 故"对黑暗畸变无特攻"
- **圣光魔法净"质"**，不修复已被破坏的形态 → 故"无法修复重伤肉身"
- **两者必须同时进行**。因此教会要求受治者归信、献纳，并贬精灵魔法为"巫术"；精灵认为圣光"只是替世界打扫尘土"。**教义不可调和，现实中却只能通过冒险者公会间接交换** → 这就是公会握住的命门。

### 2.3 斗气体系 · 人人都能获取的力量【修订 · 本轮重点】

> **魔法是天赋的，斗气是人人都能获取的。**
> 精灵独占生命魔法，人类里的施法者万中无一，圣光要教会选召、要有信仰资质——**而斗气，只要有一副身体，任何人都能练。**

**斗气的三个阶段（历史）**

| 阶段 | 时期 | 内容 |
|---|---|---|
| **① 原生** | 世界初开 | 凡有血肉的生灵皆有血气。原始斗气只是本能粗用，无阶可循、无法传承，**但不排斥任何人** |
| **② 体系化** | 太古盛世 | **战斗之神戈拉赫·断角**把斗气整理成可传授的**七阶阶梯** → 被尊为「斗气之祖」（实为"凡俗斗气体系之祖"）。从这一刻起，**没有天赋的人第一次有了路径** |
| **③ 普及化** | 大战中 / 战后 | **他把自己的徽记打碎了**（详见 3.1）。神格化作无数碎片散落大陆——斗气自此成为**全大陆唯一不看天赋的力量** |

**「人人可得」的确切含义**
- **天赋决定的是上限，不是门槛。** 任何人练斗气都能过一阶（淬体期），能走多远才看资质与苦功。
- 因此**斗气各阶的人数，大约是同阶魔法的十倍**（见 2.4 金字塔）。
- **魔法是少数人的天赋，斗气是所有人的路。** 这条分工解释了：
  - 为什么**凡俗斗气军团**能存在；
  - 为什么三十亿人口的凡人能与畸变兽潮拉锯千年；
  - 为什么公会那套「知识免费、天赋垄断」只对魔法成立——**斗气既不需要他们的知识，也不需要他们的天赋。**

**情感内核**：全大陆的斗气，是**一位兽人半神把自己的神位拆碎换来的**——而三万年后，人类把它记成了自己的武道，兽人连辩解的习惯都没有。

> **两条曲线的形状**：一阶 **400 : 1** → 四阶 **80 : 1** → 五阶 **5 : 1** → 六阶 **3 : 2**。<br>

**准神 · T4【新增】**
- **定义**：六阶本源期巅峰——**已经触摸到半神领域，但没有获得任何一枚本源徽记**。
- **战力**：可以与 T3 的四元素半神**过手、能拖很久**，但**打不赢**。
- **数量**：全大陆约 **250 人**（**斗气系约 150 / 魔法系约 100**），公开可查的不过四五十人。
- **战力内部分化极其严重**：六阶不是一层平地，而是一道**跨度极大的斜坡**——刚踏进来的与摸到门槛边的，差距可达数倍。**人数较多，但强弱悬殊。**
- **特例**：当年的卢西恩·凯德，就是这一层的**顶点**——万古以来最强的凡人。

**伪半神**：以太畸变把巨兽强行推入**本源期**，但**无徽记、无权柄** → 故称"伪"。一头伪半神 ≈ 一支万人军团。

### 2.5 神阶七则【修订 · 增一则】
1. **唯徽记可至**——神阶不是第七级台阶，而是换了一种存在方式。
2. **唯认可可用**——详见第 4 节。
3. **权柄不枯竭，肉身会残**——半神出手不消耗自己，可以久战；**但他们会受伤**，被黑暗以太造成的「**本源创伤**」不可逆，只能靠长眠压制。
4. **认可是终身的、不可让渡**——一旦被认可，徽记与你同体，**你伸手就能把它召回**。
5. **半神可以被杀死**——打到本源崩解即**形神俱灭**（火神、水神、土神、蚀主皆战死；**斗神是自碎其印**；**生命神是本源耗尽的牺牲**）；卸下权柄即**归寂**（光明）。
6. **【新】神位可以迭代**——持有者死亡或卸权后，**徽记回归无主、保持完好，它会自己选下一个人**。所以神是会换代的，三万年间已经换过很多代。
7. **神阶也受约束**——上古共约以"半神自身之道"为誓：违背者，其道崩解，徽记自行离体。

## 3. 九道本源 · 与当代神位【v6 核心重写】

### 3.1 那一代九位的结局

> **那一代半神，只活下来两个：龙神与风神。** 其余七位，都在大寂灭之战中走到了尽头——但**他们的死法各不相同**，而每一种死法都留下了一件当代事件。

| 本源 | 真名 · 封号 | 种族 | 结局 | 留下了什么 |
|---|---|---|---|---|
| **巨龙** | 阿瑟拉克斯 · **太古龙神** | 龙族 | **存活** · 重伤沉睡 | 龙岛龙祖神殿之下沉睡至今 |
| **风** | 凯瑞尔 · **无系者** | 精灵 | **存活** · 本已濒死，**被生命神以命相救** | 东境风眼的三万年风暴——里面睡着一个被同族用命换回来的人 |
| **光明** | 艾德里安 · **破晓者** | 人类 | **归寂**（卸下权柄，亲手锁印于圣山） | **光明徽记空悬三万年** |
| **战斗** | 戈拉赫·断角 · **百战之魂** | 兽人 | **自碎徽记** | **斗气成为人人可得的力量**；神位永缺 |

### 3.2 战斗之神 · 唯一自碎其印者【新增】

> **战斗徽记，是被黑暗神打出裂缝的。**

- 决战之中，**蚀主一击把战斗徽记打出了裂缝**——裂缝意味着这枚印随时可能被腐蚀、被夺、或反过来污染它的主人。
- **戈拉赫选择自行献祭。他把有裂纹的徽记彻底打碎，分成无数碎片撒向整片大陆。**
- 三重后果：
  1. 他**形神俱灭**（印碎则神灭，这是铁律）；
  2. **战斗神位从此永缺——这是绝对的，不可能被修复。** 碎了就是碎了，没有任何手段能让它变回原来那枚；
  3. **那些碎片散落古战场，成了全大陆斗气的来源**——每一块碎片对持有者都是**极强的力量来源**。

**唯一的例外（这才是这条线真正的形状）**
> **集齐所有碎片，可以使它「恢复」——但恢复到的，永远不是原来那个力量。**

- **可以恢复，不能复原**：拼回去，它也只是一枚**残缺、降级、永远到不了原高度**的印；
- **而且不能用来封神**——它已经不再满足"唯徽记可至"中"那枚完整印"的要求；
- **但仅仅是这样，就足以让人疯狂**：一枚打折的斗神之印，对凡人仍是**压倒性的力量**。

**而「集齐所有」这四个字，就是这条线的全部难度**
- 碎片在三万年里被**镶嵌、熔铸、传家、打进了兵器、也融进了血脉**；
- 兽人与矮人**没有文字**，哪有几片，全靠口传；
- **于是它散到了无法统计的程度——物理上接近不可能。**

> **这条线的张力不是"能不能修好"，而是「永远缺最后几片」。**
> **他把自己的神位，拆成了给所有人用的力量。** 而三万年后，人们只记得"斗气是人类的武道"。

## 4. 徽记法则

### 4.1 徽记本身就是认可
**八道本源**各凝一枚**本源徽记**（第九道因卢西恩而生）。它**不只是器皿**——**它的存在本身，就是"世界认可你"这件事的具象**。

- 常规路径：先被本源认可，徽记随之与你同体。
- 例外的路径：**卢西恩**。他先吸收了黑暗以太，**世界为了回应他，才凝聚出第九枚徽记**。

### 4.2 徽记的性质【修订】

| 性质 | 内容 |
|---|---|
| **不可被毁坏** | **没有任何外力能摧毁它**——S 级本源七件与五位半神都做不到。**唯一的例外是持有者自碎**（战斗之神是三万年来唯一的例外） |
| **持有者死亡 → 回归无主** | 它不会碎，只会脱离死者、**保持完好地成为无主之印**——这就是为什么蚀主死后，众神封印的只能是**一枚徽记**而不是一个人 |
| **可作为武器** | 增强与自身属性相符的力量。**但增幅并不夸张**——它不能让凡人变成神，只是让强者再强一档 |
| **可以伪造** | 见 4.3 |
| **不可强夺** | 见 4.4 |
| **不可传承** | 认可**不是人的传承，是世界的选择**。父传子、师传徒、王传臣，全部无效 |

### 4.3 伪造徽记 · 「仿印」【v6.3 重写】
- **它为什么存在**：战斗徽记在大战中**自碎成无数碎片**——凡人的斗气从此失去了可以依靠的增幅凭依。战后，人类工匠与矮人铸造师联手**把以太结晶与碎屑铸成「仿印」并量产**，专门用来增幅极强的战士。<b>这个产业，是被那枚碎掉的神格喂出来的。</b>
- **数量极少**——绝不是人人都有，绝大多数人一辈子见不到一枚。**所以看见有人佩戴，就会默认他是一位极强的强者。**
- **佩戴 = 五阶及以上**：原因不在门规，在**物理**——仿印的增幅有**承受门槛**，四阶以下的身体扛不住那股冲击，戴上反而被反噬。**「敢戴、戴得住」本身就是五阶以上的证明。**
- **它确实有增幅**：对那位战士而言是实打实的（气量、爆发、续航各抬一档），但也仅此而已——**没有权柄、无法登神**。
- **真假难分——连神都分不出**：量产工艺成熟后，仿印与真徽记在外观上已**几乎无法区分**，**就算一位真正的半神也未必分得清**——于是分不清佩戴者是**半神，还是五阶强者**（两者都扛得住）。<br>- **但普通人冒充不了**：四阶以下的身体承受不住，**戴上当场被反噬**——所以街上没人挂这个，**「敢戴」本身就是门槛。**
- **「验印师」这一行很尴尬**：没有消失，但只剩验低端货、给来历出文书、给城里人一点安慰——**真正高端的仿品，谁也验不出来。**

### 4.4 不可强夺 · 与「召回」
> 不是"你抢不走"，而是"**抢了也没用**"。

**一旦徽记认可过某人，他伸手就能把它召回。** 所以任何夺印者都只是**替人保管**——他可以拿着它走进几千里外的一座城，然后在某个夜里发现手里空了。

### 4.5 负印者
未获认可、却长期持有一枚徽记的人，称为「**负印者**」。
- 徽记在他手里**毫无作用**——纯是持有；**不排异、不压垮他**。
- 若借**特殊仪器**强行榨取，可以抽出一**丝权柄**：作用微乎其微，**但代价极重——寿命与生命会受到严重损耗**。

> **负印者是一群可怜人**：他们比谁都清楚自己手里拿的是什么，也比谁都清楚自己用不了。

### 4.6 九枚徽记的现状【v6 重写】

| 徽记 | 状态 | 所在 |
|---|---|---|
| **黑暗** | **无主 · 完好** · 随蚀主之死脱离 → **被五位半神封入异次元** | 就压在**黑暗巨洞**之下（第九道，因他而生） |
| **光明** | **无主 · 完好** · 破晓者卸权后亲手锁起 | 圣山宝库 —— **三万年无人被认可** |
| **战斗** | **碎成无数碎片**（自碎） | 散落古战场的万千战魂铠碎片之中 |
| **火** | **无主 · 完好 · 方位失传** | 神话过程中失真；**少数部落仍握着大致方位的口传线索，但从不外传、又不识文字 → 正随代际消失** |
| **生命** | **有主 · 已换代** | 精灵圣林（现任生命神） |
| **巨龙** | **有主 · 原班在位**（沉睡） | 龙岛龙脊雪峰 · 龙祖神殿之下 |
| **风** | **有主 · 原班在位**（沉睡） | 东境风眼 |
| **水** | **有主 · 已换代** | 南部深海 · 水晶宫殿（现任水神） |
| **土** | **有主 · 已换代** | 灰铁群山 · 地心殿堂（现任土神） |

**四座空位 = 四条主线**
1. **黑暗印**：封在巨洞之下，邪教想把它捞出来，让它再认一个「蚀主」。
2. **光明印**：在圣山，等了三万年——**是它选不到，还是教会没让它选？**
3. **战斗印**：碎成了碎片，散在古战场——理论上可以**重铸**，三万年无人做到。
4. **火印**：**没有人知道它确切在哪。** 位置早在神话流传中就已失真——**但不是全无线索：少数部落一直握着它的大致方位**，像一张**口传的寻宝图**。<br>　**而这些线索从不外传**，兽人与矮人又没有文字，**记忆必然随代际流失**。时间越久，知道的人越少——**到今天，只剩一个地名和一个传说。**

> **而四座空位里，唯一"完整且马上可能认主"的，就是圣山的光明徽记。**

### 4.7 以太潮汐 = 被封徽记的心跳【新增 · 由本轮推导】

> 黑暗巨洞之下的那枚印，三万年没有沉下去。它在**呼吸**。
> **每一次以太潮涨，都是黑暗徽记的心跳。**

- 周期约 **2100 年**一次，至今 **14 跳**（最近一次约 300 年前）。
- **第 15 跳本该再等 1800 年，现在就到了。**
- 与此同时，圣山的光明徽记也出现「复苏」征兆。
- **两枚沉睡三万年的印正在赛跑——它们各自想认一个什么人，而那个人就是这个故事的主角。**

## 5. 卢西恩·凯德 · 完整的堕落史与终局

| 阶段 | 内容 |
|---|---|
| **① 起点 · 万古最强的凡人** | 中央平原古武院出身。**六阶本源期的最强者**，「准神」这一层的顶点——能与半神过手，但终究打不赢。他一生所求，最初只有一件事：**证明自己比师弟更优秀。** |
| **② 缺口 · 他信仰的不是光明，是赢** | 师弟**艾德里安**被光明本源认出来了，而他没有。**他的意志早已非常不坚定**——不是坏，是**空**：他信的不是任何东西，他信"赢"。 |
| **③ 出入口 · 无意接触** | 深入西南堕落半岛的远古遗迹。遗迹深处有一道**位面裂隙**，黑暗以太自虚空渗出。他无意中接触到了它——**这种东西可以增强自己。** |
| **④ 他其实什么都没想干** | 他没有野心，不想征服、不想统治。他只是认定**这股力量能让人们变强**。<b>而此时的他，已经黑暗以太洗脑了——却自以为依然清醒。</b> |
| **⑤ 他把力量传了出去** | 因为他自己确实没事，所以他坚信**它是可控的**；但他**根本不知道这股力量会影响别人的心智**——于是他把力量分给了别人、教给了别人，<b>形成了一股不可磨灭的战力。</b> |
| **⑥ 世界回应了他** | **因他的吸收，世界凝聚出第九枚徽记——黑暗徽记**，他成为第一位黑暗半神。<b>而他并不知道自己已经「坠入」了什么。</b>（三万年来无人能复现：世界不会重复回应同一种道。） |
| **⑦ 他不被理解** | 人人都看得出那力量在害人，只有他坚持**可控**。<b>于是所有人都在反对他，只有他觉得自己是对的。</b>——这是一场他赢不了的争论，因为他已经没有"别人"的视角了。 |
| **⑧ 他开始失控** | 传播出去的侵蚀，反过来一口一口啃他自己。<b>他的意识从清晰滑向混乱。</b> |
| **⑨ 灭世，是最后才有的念头** | <b>在此之前，他从未想过毁灭世界。</b>那是意识彻底混乱之后，才浮上来的唯一一个「清晰」的想法。 |
| **⑩ 疯狂扩军 · 以半岛为核心** | 混乱中他开始**批量制造伪半神巨兽**。<b>而堕落半岛本身几乎没有生物可供畸变——所以他的兽潮，主要来自海洋。</b>他大肆掠夺海魔兽并以太改造它们。 |
| **⑪ 终局 · 他死在一个人手里** | S 级本源七件与五位半神合力，第一次强行撕开**徽记与他本体的连接**。就在那一瞬间，**一个连名字都没有留下的人类士兵**，补上了最后一击——**他形神俱灭。** |
| **⑫ 然后是沉默** | 那枚印**完好无损地浮了起来**。它不能被毁，谁也毁不掉。五位半神只能把它与虚无暗影斗篷一同**打入异次元封印**。 |

> **这个堕落最狠的地方在于：每一步他都觉得自己是清醒的。**
> 他分发力量时是好意，他反抗全世界时是自信，他想到「毁灭」时，已经不是他在想了。

> **三万年来，所有人都以为黑暗半神被封印在异次元里。**
> **其实他三万年前就死在了一个凡人手里。封在那里的，只是一枚没有主人的徽记。**
>
> **而他的核心悲剧，一句话就够：**
> **他不是被黑暗骗了，他是被黑暗认出来了。而黑暗之所以认得出他，是因为他早就空了。**

**最狠的一句讽刺**
> 他一生拼命想成为一个"**被世界选中的人**"，而最后杀死他的那个人——**没有任何天赋、没有被任何东西选中、不是什么传奇英雄**，只是一个最普通的凡人士兵。
> **战后，人们记住了卢西恩这个名字三万年；而那个名字，没人记得。**

> **📌 保留细节**：他出发时，人们叫他「**持炬者**」——因为他走在队伍最前面，手里举着火。他当年说过：**「我出发的时候，是想把光带回来的。」**

> **📌 他留下的一句话**（未必对，但三万年无人能驳）：
> **「只要光明徽记存在，黑暗就永远不会被真正消灭。」**
> —— 这句话如今是邪教最核心的教义。

## 6. 战争的真相 · 为什么八打一打了近千年

| 原因 | 说明 |
|---|---|
| **① 他杀不死** | 黑暗徽记已认可他、与他同体；**你夺走它，他伸手就能召回**，而印本身**没有任何力量能摧毁**。所以那一千年的军事目标只有一个：**把他的本体打崩，让印与他脱开** |
| **② 他的兵源近乎无穷** | 以太能强行改写野兽形态、推入本源期；只要以太还在泄露，兽潮就会再生 |
| **③ 污染是慢性失血** | 联军不是被打垮的，是**被泡软的**；千年下来能保持清醒的人越来越少 |
| **④ 半神之间谁也无法速胜** | 常态差距极小，而他高出半阶，可随时脱离战场 |

> **那一千年其实是一场持续的解剖**：诸神围攻近千年，只为创造出**一个瞬间**——让一个凡人的剑能够碰到他。而最后，真的做到了。

**伤害类型**

| 类型 | 后果 | 实例 |
|---|---|---|
| 常规创伤 | 可愈，但半神自愈以百年计 | 千年大战期间的反复负伤 |
| **本源创伤** | 黑暗以太侵入本源所致的**不可逆创伤**，只能以长眠压制 | **龙神与风神**（战后带伤沉睡三万年） |
| **形神俱灭** | 本体崩解 | 水 / 土 / 火 / **黑暗** 战死 |
| **本源耗尽 · 归于无主** | 救人耗尽自身，非被杀 | **生命**（把最后的生命传给风神） |
| **自碎徽记** | 主动击碎自己的印 | **战斗** |
| **归寂** | 卸下权柄、封存本体，徽记完整但沉寂 | **光明** |

**蚀使的战力 · 与「他站在封印正上方」【v10 补 · 附录B #13】**

| 项 | 定位 |
|---|---|
| **阶位** | **五阶顶 → 六阶边缘**；靠**与黑暗印的共鸣**越阶发挥，**不是他自己修上去的** |
| **上限** | 在**巨洞正上方**可短暂摸到六阶战力；**一离开半岛就掉回五阶** |
| **短板** | **不敢久战**——越阶靠借，借得越多，被印反噬得越狠 |
| **死结** | **他不能死在半岛之外**（一死在外面，共鸣就断），**也不敢真的取印**（取了他就只是个载体） |

**「站在封印正上方」的三条位置优势**
1. **以太白拿**——封印渗漏的以太直接供他调用，**相当于自带灵地**；别人要消耗，他不用。
2. **领域压制**——符文禁区之内，**对方的传送、通讯、大半阵法直接失效**（§9.1：半岛根本没有传送阵）。**打他，只能走路进去。**
3. **退无可退**——他掉进巨洞是**印的怀抱**；对手掉进去是死。**地利不在武器上，在「他输得起，你输不起」。**

> **于是擂台站得住**：他不是"全场最强"，**他是"在这个格子里最强"**——只要剧情逼对手**必须走进那个格子**，这场戏就成立。

## 7. 联军军械目录【v7 重写】

> **这里没有神器，只有军械。** 千年战争里，矮人出**锻造**、人类出**阵法**、半神出**本源供能**，一层层锻出来的量产与非量产装备。
> 史书把其中**七件**记成了「神器」——**不是因为它们神奇，是因为它们做得格外成功，而且恰好是半神亲手用过的那几件。**

### 7.1 三大工艺：谁造什么

| 工艺 | 掌握者 | 产出 | 关键限制 |
|---|---|---|---|
| **锻造** | **矮人** | 兵器、斗铠的主体、材料处理 | 能把以太**锁进材料**（静态固化），但**无法把以太布成法阵**——**造得出刀，造不出刀上的阵** |
| **阵法** | **人类** | 法阵、**模具**、符箓——让以太**流动**的回路 | **锻造技术一塌糊涂**；但天才造出了**可复制的阵法载体「模具」** |
| **供能** | **半神** | 最高阶产品的本源动力与材料 | 只有少数 S 级需要本源参与；**但 S 级本身是可打造的**（见 7.2） |

> **这场战争真正的技术突破，是两个种族的「短板对短板」。** 矮人有剑无阵，人类有阵无剑——**拼在一起，才有了能运转的附魔兵器。**
> 这也直接导致：**战后的人类与矮人结成西北联盟，并催生了「九炉议会」这样一个跨种族政体。**

### 7.1.1 技术从哪来：战争是加速器，不是起点【v8 重写】

> **传送阵、法阵、符箓——这些东西在人类顶峰时代就已经存在了。** 太古盛世就已造出相当数量的传送阵与法阵，**它们是古老技术，不是战时的发明。**

| 阶段 | 发生了什么 |
|---|---|
| **太古顶峰** | 传送阵、法阵、符箓**早已成熟并量产**——只是规模有限、各族自用、彼此不通 |
| **战争第二百年** | **战争把已有技术推到极限**：联军需要跨洲调度，于是八位半神各出本源之力、人类工匠施工，**把古老技术第一次覆盖了整片大陆**。同时为求生逼出了大量新东西（S 级军械、护世大阵、模具、仿印） |
| **战后** | **技术不是停滞，是倒退**——见下方三条 |

> **半神没有推进技术，是战争推进的。** 自救的压力 = 一次纯粹的、被逼出来的技术大爆发。

**战后为什么技术停滞倒退——三条，全是已经写在设定里的**
1. **战争破坏 → 技术流失**：大量节点、工坊、图纸、模具在战火中损毁，**成套技术断在了半截**
2. **人口恢复**：人力全部投进重建与生育，**没有余力研发**
3. **各族静置**：精灵闭林（13000 年）· 龙族远遁（12000 年）· 教会孤立（9500 年）· 兽人无文字分散 → **跨族技术交流中断**，没有哪一个单独的族能把整套体系接续下去

> **所以这个世界的「上古遗存」才如此值钱：那不是传说中的神器，是一套被战争打断、又被遗忘的完整工业体系。**

### 7.2 等级制度

| 等级 | 名号 | 定义 | 当代存世量 |
|---|---|---|---|
| **E** | **凡铁级** | 未经以太处理的普通兵器与甲胄 | **数以亿计** |
| **D** | **民用级** | 最简单的附魔（淬火嵌以太、基础抗性） | **数千万** |
| **C** | **制式级** | 成体系的批量制式兵器、斗铠与小符箓 | **数百万** |
| **B** | **军团级** | 团队级装备：附魔斗铠、阵旗、成套符箓 | **数万** |
| **A** | **战役级** | 能**单独改变一场战役的走向**（区域法阵、大符箓、指挥器械） | **数千** |
| **S** | **本源级** | **可打造，但只有顶尖锻造师才做得出来**（人类阵法大师＋矮人大师联手，少数需半神本源） | **极其稀少 · 仅几十件** |

**六个等级，一条线把世界劈成两半**
- **E → A 是「还能造」的那一半**：数量都还蛮多，越往上越贵，但终究是人的工艺，理论上谁都能继续做。
- **S 是「几乎造不出来」的那一半**：**全大陆有资格动这门手艺的顶尖锻造师，十指可数；一件要耗数年心血，成品率极低——出世的只有几十件。**

> 而那七件 S 级本源兵器，正是这几十件里最好的七件——**因为用它们的人最响。**

### 7.3 S 级 · 本源级（几十件中的七件）

| 名称 | 类型 | 属性 | 战时作用 | 现状 |
|---|---|---|---|---|
| **破晓圣盾** | 盾 | 光 · 秩序 | 在蚀主的腐蚀领域里撑开一片**秩序之地** | **完整** · 圣山宝库 |
| **万龙皇牙** | 长枪 | 破魔 · 穿透 | 唯一能**刺穿以太护体** | **断折** · 枪头在龙祖神殿 |
| **百战战魂铠** | 斗铠 | 战魂 · 续航 | 让使用者在兽潮里连续作战 | **崩碎** · 散落古战场（混有战斗徽记碎屑） |
| **逐风羽衣** | 护具 | 心智 · 抗性 | 唯一能在「情绪掠夺」下保持清醒 | **碎裂** · 化作风丝 |
| **焚天熔火宝珠** | 毁伤 | 火 · 熔断 | 熔断迷宫与战争工事 | **随主人崩碎** · 残骸沉于地脉（**火徽记失踪**） |

**S 级为什么这么少**：能做 S 级的**顶尖锻造师本来就十指可数**，一件要耗数年心血、成品率极低——**全大陆存世只有几十件，其中最好的七件，恰好落到了七位半神手里。**
另有两件常被并列提及，但**不属于军械目录**：**世界树之枝**（世界树自生，非铸造品）与**虚无暗影斗篷**（敌方之物，是长出来的）。

**那"几十件"剩下的去哪了【v10 补 · 附录B #12】**
（§7.2 说几十件，这里只列了 7 件 ＋ 2 件非军械 → 其余去向此前是空的）

**准确口径：约 40~50 件出世，七件最好、九件可考，其余的散了。**

| 去向 | 件数（建议值） | 说明 |
|---|---|---|
| **七件归于七位半神** | **7** | 上表——**被记住的那七件** |
| **战损崩碎、残骸可考** | 约 **6** | 与"断折 / 崩碎 / 碎裂"几件同期报销；残骸在古战场、地脉、风丝里 |
| **封存于各族圣地** | 约 **10** | 圣山宝库 · 灰铁地心 · 龙祖神殿 · 深海水晶宫 —— **外人根本见不到** |
| **公会私藏** | 约 **5** | **约 300 年前随转运行会一并被公会收编**——公会从不对外说的**一件私事**（**不是**「第五重命脉」，那四条仍是公开的四条） |
| **失传 / 沉埋** | 约 **15** | 三万年里多数连名字都没留下；**这十几件就是"寻宝线"的全部池子** |
| **在民间流转** | **0~2** | **S 级一旦露面就是地震**——史载的民间持有只有一次，那次毁了一座城 |

> **三条有用的推论**
> ① **为什么 S 级不引发战争**——绝大多数人**根本不知道它们还存在**；知道的那批人**已经拥有它们**。
> ② **公会那 5 件是隐藏设定**——它可以不动用，但**它一直有**。任何一次"公会突然翻脸"，从此都多了一层解释。
> ③ **「公会有却为什么不用」——因为一用就等于站队。**
>    公会的权力来自「**谁都能用它**」；S 级一亮出来，各族会立刻要求**收回、共管、或干脆认定它已经选边**。
>    **于是那 5 件最合理的用法是「摆着」**：作为谈判桌底下的**威慑与保险**，而不是武器。
>    > 这一条必须写死——否则「公会藏有 5 件 S 级」会直接推翻它维持了三万年的中立叙事。

### 7.7 为什么改名

**「联军九器」有两个毛病：一是暗示世上存在「神器」，二是暗示只有九件。** 实际战时产出的是一整套**四类工艺制品的军械体系**。
而史书只记住那七件，是因为**用它们的七位半神，一个比一个有名**——**被记住的从来不是物件，是拿它的人。**

## 8. 六大种族

| 种族 | 天赋定位 | 寿命 | 政权 | **当代的神** |
|---|---|---|---|---|
| **人类** | 枢纽种族 · 唯一能并修双系 | 约 **100–120** | 城邦联盟 | **0 位**（黑暗已死、光明空悬三万年） |
| **精灵** | 生命魔法主宰 · 精神力冠绝 | 约 1500–2500 | 圣林长老议会 · 闭林 | **2 位**（生命·新任 ＋ 风·原班） |
| **矮人** | 以太赋形 · 绝对中立 | 约 **400–500** | 九炉议会 | **1 位**（土·新任；火印失踪） |
| **兽人** | 生命力极致 · 天生战士 | 约 **300–500**（个别品种 **1000+**） | **无统一政权** | **0 位**（斗神自碎，永缺） |
| **龙族** | 魔武双通 · 天生无相消 | 约 3000–5000 | 互不统属 · 无王 | **1 位**（龙神·原班） |
| **海裔** | 潮汐系 · 深海守望 | 约 800–1500 | 深海城邦 | **1 位**（水·新任） |

**各族的隐藏设定**
- **精灵**：约 13000 年前遭大规模掠捕（「**药奴之痛**」），此后**主族退入生命之城、以议会方式闭林**——但**从未彻底断绝**，仍经公会之地交易，**且外围精灵至今仍在被贩卖**。当代有**两位神**：**约 3000 年前被徽记认可的现任生命之神**，以及三万年未替换的**原班风神**（睡在东境风眼里）。
- **矮人**：独精**以太赋形**（只能固化、造不出回路）；地心殿堂里是现任土神；**火徽记失踪**。**不是奴隶社会**，山地缺粮布日用，**定期进城采购**；**在西北与人类合并成「九炉联合体」**。
- **兽人**：**斗神自碎其印，把神位变成了人人可得的斗气，兽人因此一无所有。** 有个「诸部议会」的名号，**但没有谁真的在意它**——谁强听谁的，谁打赢听谁的。
- **龙族**：**龙祖神殿没有祭司、没有仪轨、没有议事**——有信仰，无组织。殿下沉睡的龙神是三万年来最老的两位神之一。
- **海裔**：现任水神由海裔继承，守着沧澜潮音珠。
- **人类**：**这个世界上唯一出过"灭世者"的种族，也是唯一两道印全空的种族。**

### 8.1 族群结构 · 与这个世界的奴隶制【v6.3 新增】

> **一句话：精灵和矮人都不是一个「民族」，而是一群「聚落」。**
> 精灵以**议会**形式联合，矮人以**氏族方式聚拢**——像一串串各自过日子的村子，被某个中心勉强拴在一起。而兽人，连这串绳子都没有。

**🌿 精灵 · 一族多分**
- **不是一个族，是一堆族群**，以议会形式联合，各自为政，**内部并不团结一心**。
- **主族**聚居于**生命之城**，人数最多，是维系整族的那根绳——但它只是「**最大**」，不是「唯一」，更不是「服从」。
- **闭林没那么彻底**：主族仍通过**公会之地（誓约之地）**与外界交易、沟通。**圣林关的是门，不是窗口。**

**🕳️ 黑暗森林族 · 整族里的一半愤怒**
- 有些精灵早早就**投向黑暗以太**，成了「**黑暗生命系**」——他们不接受「生命就是一切」这套教条。
- **但不是人人都碰过以太。** 这一支混着两种人：**① 真正接触过黑暗以太的**；**② 只是主张对人类动武的**（没碰以太，只是恨）。前者更危险，后者人更多。
- 他们具备类似人类的情感——**不尊重、也不敬畏生命**，会杀人，会与人类正面对抗。
- **而精灵尊重他们，他们也尊敬生命女神**（生命之始 · 生命伴生）。
  > **这是分裂的精灵唯一不争的一件事：可以反目，可以杀人，但谁也不能不认生命之神。**

**奴隶制为何无人管 · 根本原因【v8 重写 · 据反馈】**

> **根本原因：奴隶制不是某一方的恶行，它是这个世界的共同制度。**

**第一层 · 制度本身**
**整个大陆都处在这套制度里**——它不是人类单独造的孽，而是**各族共同默认的社会结构**。所以没有哪一方「有资格」站出来指认另一方：**大家都在里面。**

**第二层 · 精灵内部同样是贵族制**
精灵社会**同样分三六九等**——**贵族制必然伴生奴隶制**。对精灵贵族而言，最底层那些人本来也只是「**民众**」，并不比别族的民众更值得他们出手。
> **他们不救，不是因为仁慈或冷血，而是因为在他们的等级里，那本来就不是"自己人"的事。**

**第三层 · 为这件事翻脸不值当**
和平、贸易、共同抗灾、互通有无——**为了几个底层人与人类翻脸，本身就不划算**。
> **沉默不是道德缺陷，是一笔算得过来的账。**

**第四层（神这一层 · 辅助）**
即便真有一位精灵贵族想管——**生命之神的权柄是「滋养与守护」，她无法动用毁灭之力去对付奴隶贩子**。
> **既不划算，也做不到。** 四层叠起来，这件事才会持续三万年而无人过问。

**奴隶制 · 来源与规则**

| 来源 | 数量 | 谁抓谁 | 备注 |
|---|---|---|---|
| **人类** | **最多** | 既抓异族，**也互相抓** | 既是最大来源，也是最大买家 |
| **兽人** | **次之 · 最典型** | **弱肉强食**，既被抓也抓人 | 体力强、繁衍力强 → 需求最大，也因此最常被卖 |
| **精灵** | **再次** | **只被抓，从不抓人** | 主要是**圣林外围的精灵**；价格最贵，**无人过问** |
| **矮人** | **最少** | **从不抓人**（矮人不是奴隶社会） | 被掳的多是外出采购的商队 |

**三条不成文的规矩**
1. **奴隶极贵**——尤其精灵，价格是硬通货级别；
2. **没人管**——公会不管、城邦不管、精灵不报复，谁也不愿得罪这条利益链；
3. **主族不救**——**精灵内部同样是贵族制**，底层人对他们只是「民众」；为这事翻脸不划算；**即便想管，生命神的权柄也不允许她动用毁灭之力**。
   > **所以「闭林」其实是把自己关起来的、被动的忍耐，而不是一种封锁。**

**🔨 矮人**：**不是奴隶社会**，只是以族群方式聚拢而居。住在**火山周围**——金属矿藏兵器是全大陆最好的，但**山地不产粮、不产布、不产日用**，所以每隔一阵各氏族就要**下山进城采购**。这条商路是矮人与外界的全部联系，**也是他们最常被掳走的地方。**

**🦴 兽人**：以部落为单位，**弱肉强食**：谁强听谁的、谁打赢听谁的。有个「**诸部议会**」的名号，**但没有谁真的在意它**——能一起打仗时凑在一起，散了就各走各的。**有形式，无约束。** 也因此，一个部落败了，**整座部落都可能变成商品。**

> **这个世界在「敬重生命」这件事上，彻底分裂成了三层：**
> ① **生命之神与精灵**——奴隶制本就是各族共有的制度，**精灵内部同样分三六九等**，底层人只是「民众」；为这事翻脸不划算；**即便想动，神的权柄也不允许**；
> ② **人类与城邦**——吃这条利益链，也吃精灵的血；
> ③ **黑暗森林族**——不信「生命就是一切」，所以他们动手杀人。
> **而精灵尊敬黑暗森林族，人类捕获精灵，公会两头收钱——三者互不干涉，维持了三万年。**

### 8.2 半人半精灵 · 一个由奴隶制生出来的族群【v7 新增】

### 8.3 外海生态 · 为什么海洋才是真正的危险区【v7 新增】

- **堕落半岛本身几乎没有生物**，所以蚀主的兽潮**主要从海洋来**——他大肆掠夺**海魔兽**，以太改造它们。
- **战后没人能一条条清理**：被打散的异化魔兽与**伪半神巨兽**大量滞留**外海**，在海上形成了一个危险的野生种群。
- **大陆护世大阵**（战时造的 **S 级**防御法阵）**罩住了整片大陆**——因此这些巨兽**只能待在外围，不太敢深入内海与近岸**。
- **伪半神巨兽是有意识的**：被侵蚀但**并未完全失去自我**，因此会**主动对人类发起反制**，而不是无脑冲锋。

> **结果就是这个世界的海域被劈成两半：**
> **内海 = 相对安全**（有大阵庇护、有航线、有海裔）；**外海 = 真正的危险区**（异化魔兽、伪半神巨兽、无人清理）。
> **而人类与海裔都聚在内海一带——于是内海沿岸成了五族杂处的走廊。**

### 8.4 公会与精灵：这段关系是怎么来的【v7 补因果】

> **不是精灵选择了公会，是公会先开出了精灵无法拒绝的条件。**

- 公会以**绝对中立**为立身之本，于是**主动向精灵提出**：由精灵提供治疗、分享生命魔法，**而公会保证它不做任何势力的代言人**。
- 精灵这才接受——**因为除了公会，没有任何人能让精灵相信「交出去之后不会被拿去奴役人」。**
- 作为回报，公会也向精灵提供**治疗方案、外部情报与物资通道**。
- **于是精灵与公会的关系是全大陆最好的**——它是精灵唯一信任的对手，也是精灵**唯一**的窗口。

### 9.1 大陆传送网【v6.1 新增】

> **大寂灭之战留下了四件遗产**——**七件 S 级兵器**、**黑暗巨洞上的封印**、**大陆护世大阵**、**大陆传送网**。

**怎么来的**：战争第二百年，联军需要在**半岛前线**与**各族后方**之间调动军队、补给与伤员，普通行军来不及。于是——**八位在世的本源半神（光明·巨龙·生命·战斗·风·火·水·土）各出本源之力，人类工匠具体施工**，符文底座来自矮人的**以太赋形**工艺，从誓约之地向外辐射，把大陆的主要城邦串成一张网。<br>**八道权柄同时供能，这张网才覆盖得了整片大陆。**<br>**为什么施工的是人类**：战时各族精锐都在前线流血，只有人类城邦联盟的工匠行会能拿出成建制的工程队——**于是图纸、口诀、阵图，全在人类手里。**

**战后交给谁**：半神全部归隐沉睡，**但人类可以复建**——三万年来人类工匠一直在钻研阵图，**现代人类已经掌握复建技术**，各城邦的自建线遍布大陆。<br>只是有**质量分层**：半神亲手造的**原始节点**载荷高、稳定、能跨洋；人类复建的**支线**更脆、更慢、更贵。而维护与调度最初由**人类工匠行会**执掌（公会的前身），**约 300 年前被整合为冒险者公会。**<br>**各族为何不研究**：精灵不接（闭林）、龙族不接（拒绝）、海裔无法建、兽人不服管；矮人提供符文底座，但**阵法不在他们手里**——**人类凭这套技术成了大陆的工程垄断者**，这是「枢纽种族」的第三个支柱（前两个：双系并修、地理居中）。

**六条硬规则**
1. **只能点对点**——只能在既定节点之间传送，无法任意坐标；主干线路是固定的，**战略要冲都在路线上**。
2. **有载荷上限**——重量与人数都有限，**军队无法整军传送**，只能走信使、补给、小队与伤员 → **「传信不传兵」**。
3. **耗以太**——每次启动都烧以太，账面由公会结算。
4. **需凭证**——凭公会票据或通行印才能启动，**公会不发，你就走不了**。
5. **技术在人类手里**——图纸与口诀出自战时的人类工匠行会，三万年由他们及其后人复建、扩容；**精灵不接、龙族不接、海裔无法建、兽人不服管**，矮人只有符文底座。
6. **质量分层**——**原版主干**（半神所造：稳、快、重）vs **复建支线**（人类所造：脆、慢、贵）。真正值钱的永远是主干上的那几个节点。

**谁接入、谁没有**
- **接入**：人类城邦联盟 · 矮人九炉 · 圣山 · **誓约之地（中央枢纽）** · 公会各地分部
- **不接入**：**精灵圣林**（这就是闭林的物理保证）· **龙岛**（龙族拒绝）· **深海**（无法布设）· **兽人荒原**（部落不服管）
- **堕落半岛没有传送阵**——那是符文禁区，所以打进去永远只能走海路

**票价与管制【v10 补 · 附录B #10】**

> 一张网光有规则还只是"技术"——**加上票价和证件，它才变成"权力"。**

| 环节 | 怎么收 | 效果 |
|---|---|---|
| **票价** | 按**里程 ＋ 载荷**计，用**以太结晶**结算；人比信贵得多 | **信三天到，人走三个月** →「口信」成了一门正经生意 |
| **常客票** | 行商、公会编内、军务有**包年票** | 有票的人是**大陆上最快的那批人**；没有票的人不是 |
| **管制三证** | **通行印**（身份）· **货引**（报关）· **公会票据**（默认凭证） | 三证缺一，**节点不启动** |
| **黑名单** | 公会可对**个人 / 货种 / 整座城邦**挂黑 | 挂了黑**你只能走路**——对边陲城邦等于死刑 |
| **禁运名单** | 大宗奴隶 · 半岛产一切 · **未鉴定上古遗物** · 超量以太结晶 | **于是走私永远走海路**——半岛那条走私线由此存在 |
| **新建审批** | 自建支线的**图纸需报公会备案** | **入网即受管**（§11）——备案制让"技术扩散"仍在公会眼皮底下 |

> **票价 ＋ 三证 ＋ 黑名单 ＋ 禁运 ＋ 备案 ＝ 五道闸。**
> **公会不需要养军队——它只需要决定谁的信今天能到。**

**它给公会的权力，是所有里最硬的一条**
公会握着的不止是悬赏、任务、治疗与半岛发证权——**它握着整个大陆的交通命脉**。**它可以切断任何一座城邦的传送**：切断三天，那座城就变成孤岛——商路断、援军断、消息断、药材断。
> 于是「中立」有了新的读法：**不是它没有力量，是它选择不把线拔掉。**

**当代的引信之三 · 这张网三面受敌**
> ① **垄断被稀释**——三万年技术扩散，各城邦自建线越来越多，公会正从「**唯一**」退化成「**最大**」；
> ② **潮汐会让全网失灵**——第 15 次潮涨时以太浓度剧变，**无论公会的线还是自建的线，一起过载**；
> ③ **邪教在切断它**——切线、毁节点，不需要攻城，只要让路断掉。
> **公会手里的治疗与半岛发证权可以被人绕开，只有这张网绕不开——而它正同时被稀释、被超载、被破坏。**

**军事上的命门**：当代**五位在位神**分居的圣地（龙岛雪峰 / 东境风眼 / 精灵圣林 / 深海宫殿 / 灰铁地心）就是五道世界级防线——而**上古共约禁止他们直接出手**。**神就在那里，却不能下场。** 这是全设定最尖锐的一条张力。

### 10.2 大寂灭之战 · 关键节点

1. **六阶准神卢西恩·凯德**——万古以来最强的凡人——因始终无法超越被光明选中的师弟，**意志渐空**
2. 深入西南堕落半岛远古遗迹，**无意接触自位面裂隙渗出的黑暗以太**，发现它能增强自己
3. 成为**世界上第一个主动吸收外界黑暗以太的强者**
4. **因他的吸收，世界凝聚出第九枚徽记**；他成为第一位黑暗半神
5. 以堕落半岛为根基，批量制造伪半神巨兽；**近千年**拉锯战
6. **联军锻器**——灰铁群山九炉全开，各族合力锻出七件兵器
7. **战斗之神自碎徽记**——戈拉赫的印**被蚀主一击打出裂缝**，他选择自行献祭，**把它分成无数碎片撒向大陆**；印碎则神灭，他形神俱灭；**而那些碎片，就是后来全大陆的斗气**
8. **生命 / 水 / 土 / 火之神接连战死**——布罗姆·熔心战死于荒原，熔火宝珠随他崩碎，那一带烧成焚天活火山；**火徽记就此下落不明**
9. **无系者重伤**——凯瑞尔在东境被围杀，力竭而逃，**本源重伤**；逐风羽衣碎裂为漫天风丝（**人活着，兵器碎了**）
10. **终局决战 · 黑暗巨洞现世**——破晓者以身为锚压制蚀主；半岛中心被轰出**永不愈合的黑暗巨洞**
11. **蚀主被击杀**——七器与五位半神合力撕开徽记与本体的连接，**一个人类士兵给出最后一击 → 形神俱灭**
12. **众神封印的是徽记**——印完好无损地浮起，谁也毁不掉；五位半神将其与虚无暗影斗篷**打入异次元**，就压在黑暗巨洞之下
13. **破晓者归寂**——他没有受致命重伤。战后他亲手**卸下权柄、把光明徽记锁入圣山**；从此**光明神位空悬三万年**
14. **战后遗留**——巨洞以多层半神符文压制；**那套符文是半神沉睡前的最后一手，无人可续**
15. **神位继任开始**——生命、水、土的印回归无主后**各自选中了原种族的后继者**；此后三万年间不断换代
16. **上古共约 · 誓约之巅立约**——五位幸存半神（龙神、风神与三位新任者）立下三条铁律，**此后禁止直接干预凡俗**
17. **誓约纪元启幕**

**三条铁律**
1. 半神禁止直接动用本源屠戮凡俗、操控王朝战争
2. 大陆中央誓约之地永久中立，为各族唯一交流缓冲带
3. 若位面壁垒崩溃，所有半神必须全员苏醒救世

> **铁律的边界**：它只是**幸存半神之间的盟约**——对已经死去的蚀主没有任何约束力，**而对当代五位在位神，它是三万年不可越过的墙**。

### 10.4 以太潮汐 · 当代的引信
- **机制**：黑暗巨洞之下的封印是一次性遗产——**无人可续、无人可修**。三万年衰减之下，以太外泄呈周期涨落：**平均约 2100 年一次「潮涨」，至今已历 14 次**（最近一次约 300 年前）。
- **本质**：**那是被封徽记的心跳。**
- **潮涨三征兆**：**魔物增殖 / 邪教复苏 / 遗迹解封**
- **当代的异常**：第 15 次**本应在约 1800 年后才来，现在就到了**——而且比历次都强
- **第二根引信**：圣山的光明徽记近数十年出现异动

> **「潮」是这个世界的记年单位。** 一次潮涨就是一场改写大陆格局的大灾变——民间记年不数年份，数潮。

### 10.6 历法与纪年【v10 补 · 附录B #8】

**两套纪年并行，一套给官府，一套给百姓**——这本身就是一条世界观信息：**官府记的是秩序，百姓记的是灾难。**

| 纪年 | 谁用 | 怎么算 | 例 |
|---|---|---|---|
| **潮数纪年** | **民间 · 冒险者 · 各族部落** | **一次潮涨 ＝ 一个「潮」**，往前倒数 | 「那是上一个潮的事了」 |
| **誓约纪元** | **城邦官府 · 教会 · 公会文书** | 以三千年前那纸停战书为元年 | 誓约纪元 30000 年 · 静潮三月 |
| **建炉纪年** | **矮人九炉 / 西北邦** | 以九炉议会立约之年为元年 | 建炉 1412 年 |

**为什么百姓记潮不记年（这条最重要）**
> **对一个凡人来说，「年」什么也不说明，「潮」会决定他今年能不能收到粮食。**
> 十四次潮涨改写了大陆格局十四次——**这才是他们的时间刻度。**

**历法细节（建议值）**
- 一年 **12 个月、360 天**；余 **5 天**为「**无月日**」，各族各过各的，**不计入任何纪年**。
- **每月按潮势命名**：**潮起 / 潮盛 / 潮落 / 静潮** 四组，每组三月——**连月份名都在提醒你这个世界怕什么**。
- 各族有自己的月名；**公会文书统一用「誓约纪元 ＋ 月份序号」**——这是公会"中立"的技术基础（§11）。
- **第 15 次潮涨没有对应的月名**——它一旦到来，历法本身要改。
  > **可用的细节钩子：民间已经开始提前给那个月造新词，而教会禁止任何人写。**

#### 人类城邦联盟 · 「数十城邦」是怎么分的【v10 补 · 附录B #9】

> 「数十城邦」此前只是一个形容词。**没有骨架，联盟就只是一个背景音。**

**定数（建议值）：47 座城邦**——正好卡在"数十"上，也够让读者相信它**不是铁板一块**。

| 分区 | 城邦数 | 特征 | 关键设定 |
|---|---|---|---|
| **内圈 · 三强** | **3** | 最早建城，握传送网**主干节点** | 谁坐拥主干，谁就能在联盟里多说一句话 |
| **中环 · 十七邦** | 17 | 商业与学院城 | **学院 / 古武院**（§14.1 第三条路）基本都在这一圈 |
| **外环 · 二十七邦** | 27 | 边城 · 军镇 · 商道节点 | 灵地归属争端 · 兽潮第一线 · **奴隶贸易的口岸** |

**联盟的三条制度事实**
1. **不是帝国，是停战书**（§11）→ 联盟**没有常备军**，只有各邦自己的镇国编制；**战时才推统帅**。
2. **没有神** → **人类是唯一「神位全空」的大族**——这是联盟一切不安全感的根。
3. **城市自治，联盟只管三件事**：**传送网对接 · 联防互保 · 对外议约**。其余各邦各说了算。

**联盟内的三个冲突接口（可直接拿去写戏）**
- **内圈 vs 外环**：主干节点的**票价与配额**——外环边城永远排在后面（§9.1 补）
- **共和 vs 王政**：47 邦里两种政体并存（§14.3），**通婚、弑亲、继承权**三件事没有统一法律
- **守旧 vs 开明**：是否承认**九炉联合体**为同胞——联盟里有人把西北邦当叛徒，有人当亲戚

> **「数十城邦」由此变成：47 个各自有理的、没有神的、靠一纸停战书捆在一起的人类政体。**

### 11.1 两个被补上的政体【v7 新增】

#### 🏛 九炉联合体 · 「九炉议会」/「矮人帝国」/ 西北邦

> **它不是矮人的国家，是人类与矮人「合」出来的国家。**

- **位置**：主大陆**西北**（灰铁群山及其周边低地）<span class="mark add">位置由我设定</span>
- **成因**：**人类有阵法无锻造，矮人有锻造无法阵**——两族的短板完全互补，于是**西北的人类与矮人结成长期联盟**，最终合并成一个政治体。
- **「九炉议会」由人类与矮人共同建立**，不是一个纯矮人的机构。
- **人口结构**：两族往来过于频繁，且**彼此非常相似**——于是**产生了大量混血种**。
- **身份认同倒置**（这条最要紧）：<b>那一块的人类更认同矮人，不认同人类。</b>他们自视为这个联合体的人，而不是「人类的一员」。
- **多个称号**：**九炉议会**、**矮人帝国**、**西北邦**……外人各叫各的——<b>而他们自己其实不太在乎叫什么。</b>
- **它是一块封闭独立的地带**：与中央平原的人类城邦联盟只是名义上的同胞，实际各行其是。

> **这条设定的真正作用**：它打破了「六大种族各自成国」的整齐格局——**世界上存在一个跨种族政体，而且那块地方的人类，不认自己是人类。**

#### ⚖️ 誓约之地 · 公会自治领（五族混居的中央地带）

- **位置**：内海西岸、大陆中央——**正是当年几位半神坐下来开会的地方**，也是冒险者公会的中心。
- **性质**：**由冒险者公会自治**，法律极简，**尊重奴隶制**。
- **五族混居的「大杂烩」**：沿内海的这条巨大脉络上，**兽人、海裔、人类、精灵、矮人**齐聚，各自都有庞大群体——矮人在这一带的居民甚至比在山上还多。
- **两套并存的经济**：**官方拍卖行**（合法、公开、税费齐全）与**庞大复杂的黑市**（违禁品、来路不明的上古遗物、奴隶）**隔着一条街同时运转**。
- **为什么大家都肯来**：因为它**中立**，因为它**不管闲事**，因为**谁都能在这里卖掉不该卖的东西**。

> **于是「中心」这个词有了两重含义：地理上的中心，和道德上的无人区。**
**三条权力命脉**：教会的净化、精灵的治疗、半岛的遗宝与通道——**全都要经过冒险者公会。**

### 11.2 教会教义与异端定义【v10 补 · 附录B #11】

**教义三基（只有三条，其余全是这三条的推论）**
1. **光明印在圣山，且它终将自己选择。** → 教会的正统身份是**守候者**，不是**拥有者**。
2. **净「质」不治「形」。** 圣光只让扭曲的以太回归自然（§2.2），**肉要靠精灵** → 教会必须承认**自己有一半是残缺的**，这是一切教内张力的源头。
3. **蚀主已死，但黑暗印还活着。** → **战争没结束**，只是从"打他"变成了"守住封印"。

**「异端」的四级定义**（越往后越重；**而"谁有权判定"本身就是教内争夺的东西**）

| 级 | 名称 | 定义 | 处置 |
|---|---|---|---|
| **Ⅰ** | **偏差** | 对教义的解释与正统不同 | 辩论 · 训诫 |
| **Ⅱ** | **僭越** | **未经遴选而自称承接圣光** | 剥夺教职 |
| **Ⅲ** | **涉暗** | 接触黑暗系 · 佩戴仿印 · 买卖半岛之物 | **交公会发落**——教会自己不动手（这正是"半岛发证权"的另一面） |
| **Ⅳ** | **蚀染** | 体内确有黑暗以太 | **不判，直接净化**；净化失败者 → **公会的净化任务** |

**被蛊惑者能否被救回（伦理核心）**
> **能，但代价不对等，而且制度上几乎做不到。**
> - **圣光**只能把扭曲的以太**推回自然态**，**推不回已经变形的肉**（§2.2）→ 人回来了，形不一定回来。
> - **精灵的修形**能把肉修回去，**但清除不了黑暗以太** → 两者必须**同时、同地、由两族共同执行**。
> - 而**精灵闭林、教会不认精灵的法** → **于是"救一个人"在制度上几乎不可能。**

> **这就是 §2.2 那条"公会的命门"落到实处的样子：不是抽象的"必须经过公会"，是具体到某个村子里那个被咬了的孩子。**

## 12. 冲突的层级与节奏【v9 新增 · 参考多部优秀作品的格局骨架】

> **这一节的思路来自《蛊真人》《诡秘之主》《剑来》《冰与火之歌》的共同点：**
> 它们都不是"打得更狠"，而是**每跨一层，看到的敌人性质完全变了**——家族 → 城 → 宗门 → 国 → 大陆 → 天下（蛊真人）；序列 → 组织 → 历史 → 世界（诡秘）；江湖 → 庙堂 → 天下（剑来）；诸侯 → 铁王座 → 长夜（冰火）。
> **没有这张梯子，"七阶"就只是一个数字，而不是剧情。**

| 层 | 视角所在 | 这一层真正的敌人 | 这一层的「宝」 |
|---|---|---|---|
| **第一层 · 城邦** | 一~三阶（8 亿 → 3500 万） | 地痞、帮派、小型魔物、奴隶贩子、黑市骗局、公会分部的刁难 | 任务报酬、制式装备、**战魂碎片的边角料** |
| **第二层 · 区域 / 国家** | 四~五阶（405 万 → 6 万） | 城邦权力、教区、商会、**灵地归属、军械市场、九炉联合体的扩张** | **灵地使用权**、B/A 级装备、传承资格 |
| **第三层 · 大陆** | 六阶（250 人） | **准神之间的博弈、四座空位、神位继任、圣地归属、内鬼名单** | S 级军械、印的碎片、**神位** |
| **第四层 · 位面** | 七阶（9 位） | 徽记、封印、半神、**虚空** | 神格本身 |

**两条铁则**：

1. **上一层的敌人不是下一层的弱化版，而是完全不同性质的敌人。** 城邦里的恶霸不会因为你变强就变成邪教徒——你到第六层，面对的是另一套规则。
2. **当代四层同时点火，但每层烧的东西不一样**：
   - **城邦层**：第 15 次潮汐 → 兽潮、粮价、逃难潮、悬赏激增；
   - **区域层**：公会三面受敌、九炉联合体扩张、奴隶贸易趁乱做大；
   - **大陆层**：四座空位同时松动，**内鬼名单**开始有人心照不宣；
   - **位面层**：封印衰减 + 光明印复苏 + **两枚印赛跑**。

> **这就是这个世界"能写下去"的根本原因：四层各有各的火，互不重复。**

## 13. 修行的现实：寿元、瓶颈、灵地与成本【v9 新增 · 参考《蛊真人》《修真》类作品】

### 13.1 寿元阶梯：四阶与六阶是两道坎

**基础寿命是种族性的，修行能突破——但要到四阶才开始明显跳档。**

| 阶 | 人族寿元 | 阶段 |
|---|---|---|
| 一阶 淬体 / 感知 | **100–120** | 与常人无异（斗气本身已带来轻微延寿） |
| 二阶 凝气 / 引灵 | 110–140 | 微延 |
| 三阶 罡气 / 术式 | 130–170 | 开始超出常人 |
| 四阶 战魂 / 领域 | 160–220 | **第一道跳档** |
| 五阶 斗域 / 大魔导 | **200–250** | 突破凡物上限（即「高阶法师 200+」） |
| 六阶 本源（准神） | **400–600** | **第二道跳档：触及世界底质** |
| 七阶 神阶 | 与本源同寿 | |

**各族在其基础上同比放大**：兽人基础 300–500 → 高阶可破千；矮人 400–500 → 高阶更长；精灵 1500–2500 → 高阶可至近万；龙族 3000–5000 → 古龙可能破万。

**⚠ 一条必须守住的天花板**：**没有任何凡俗修行者的寿命能接近三万年。** 即便是龙族六阶的绝对上限（约一万年），**也只有那场战争的三分之一**。
→ **所以「无人记得大寂灭之战」这条核心设定，不依赖任何前提，天然成立。**

**寿元带来的直接红利（很值钱）**：

> **六阶那 250 人里，一大半是活了几百年、上千年的老怪物。**
> 所以「**公开可查的不过四五十人**」不是因为他们少，而是因为——**活得够久的人，早就退出了世俗竞争。**
> **六阶的"隐世"，是寿元的副产品。** 这条同时解释了：准神为什么难找、各族"镇族强者"为什么从不出手、以及为什么他们的传说都模模糊糊。

### 13.2 三重门：五阶为什么只有 150 个能上去

**不是天赋不够，是「门」就那么几扇，而且都被人占着。**

| 门 | 内容 | 为什么稀缺 |
|---|---|---|
| **① 地利 · 灵地** | 必须在**以太富集或有本源残留**之处"沉下去"，才能撬动世界底质 | **最浓的灵地全在神的圣地与禁区里**（见 13.3） |
| **② 材料 · 资源** | 突破所需的消耗品：淬骨锻体材料、以太结晶、以富集地为引的药剂 | **贵，且供不应求** |
| **③ 机缘 · 触底** | 需要一个"真正沉到底"的契机：古战场的本源残留、绝地的濒死、或他人的传承 | **求不来** |

> **这三重门，就是这个世界所有冲突的来源。** 人不是打不过谁，是**进不了那扇门**。

### 13.3 灵地地图：最浓的以太都被人占着

| 灵地 | 属性 | 归属 | 凡俗能否使用 |
|---|---|---|---|
| 精灵圣林 | 生命 | 精灵（闭林） | **否** |
| 灰铁地心 | 土 | 矮人（地心殿堂） | **否** |
| 深海宫殿 | 水 | 海裔 | **否** |
| 东境风眼 | 风 | 风神（沉睡） | **否** |
| 焚天活火山 | 火 | 无人（绝地） | **否**（物理不可达） |
| 古战场 | 战斗残留 | **公会发证** | **半**（付费 / 凭证） |
| 誓约之地 | 混合 | 公会（自治领） | **半**（付费） |
| **野灵地** | 混杂 | **无主** | **是 —— 唯一能抢的** |

**于是冲突的主战场一目了然**：各族、公会、宗门、黑市、邪教——**抢的从来不是宝物，是「无主的散灵地」。**
而它天然分布在外围、废弃地带、灾变遗址——**与怪物潮、与遗存、与奴隶贸易重叠。**

**野灵地的具体分布【v10 补 · 附录B #7】**
野灵地**不是随机的**，它只出现在三种地方——**而这三种地方恰好都是"没人管"的地方**：

| 类型 | 成因 | 典型位置 | 与什么重叠 |
|---|---|---|---|
| **灾变遗址型** | 潮涨 / 大战打散了原本的灵脉，浓度过高又无主 | 近世遗存废墟（§10.5）· 上古战场外围 | **魔物 · 遗存** |
| **边陲废弃型** | 各族都不要的边角：荒原尽头 · 群山缝隙 · 沼泽 | 兽人荒原北部 · 灰铁群山外缘 · 内海西岸滩涂 | **奴隶贸易 · 黑市** |
| **封印渗漏型** | 靠近巨洞 / 封印，以太被"漏"出来 | 堕落半岛外围三处无名礁 · 圣山东麓 | **邪教 · 畸变** |

**数量（建议值，可调）**：全大陆已登记的野灵地约 **200~300 处**；够得上"修行福地"级别的 **不超过 40 处**；**同时无主且可用的不超过 10 处**。
> **「那十处」就是全大陆所有散修、宗门、黑市、邪教在抢的那口锅**——§13.3 说的"抢的不是宝物"，落到数字上就是这十个名额。

### 13.4 修行的日常成本

| 体系 | 日常成本 | 谁付得起 |
|---|---|---|
| **斗气** | **血气损耗需食补与药浴**（大量肉食、锻骨药材）；淬体要**锻体材料**；高端要**战魂碎片** | 贵族、军中、公会编内 |
| **魔法** | **精神力恢复靠冥想与时间——这钱买不到**；施法需符纸媒介；高阶必须**常驻灵地** | 有闲的富人、法师塔、教士 |
| **符箓 / 阵** | 原料：兽皮、矿粉、以太结晶 | 行会、商会 |

> **结果：斗气养不起的人练不动，魔法没时间的人练不动。** 「人人可得」讲的是**门槛**，不讲**钱包**——这正是大多数人停在一阶的真正原因。

**货币【补 · 建议】**：**金银为日常通货；大宗结算用「以太结晶」；黑市顶级硬通货是「战魂铠碎片」。**

## 14. 上升路径 · 组织内部 · 强者的准则【v9 新增 · 参考《全职高手》《猎人》《佣兵天下》】

### 14.1 普通人的五条路

| 路径 | 怎么走 | 特点 |
|---|---|---|
| **① 公会冒险者** | 接任务 → 攒资源 → 升执衔 → 接更难的任务 | **最主流**，也是**唯一"不靠投胎"**的一条 |
| **② 城邦军队** | 军功换资源与制式装备；四阶以上可入「镇国」编制 | 稳定、慢、受制于城邦 |
| **③ 学院 / 古武院**（卢西恩出身） | 正统师承、系统训练 | 要天赋，也要钱——**它筛的就是这两样** |
| **④ 商会 / 行会** | 锻造师、符箓匠、药师 | **不靠打架也能走到四阶**——技术型上升通道 |
| **⑤ 野路子** | 黑市、战魂碎片、仿印、奴隶赃物 | **最快也最危险**，而且到四阶就撞上制度的墙 |

> **五条里只有第一条是「公平」的。——这就是冒险者公会存在的根本理由，也是它能维持「中立」的民意基础。**

### 14.2 统一分级制：一套 E ~ S 贯穿全书

**军械、任务、执衔、遗存，用同一套字母**——读者只需学一次。

| 用途 | 分级 | 说明 |
|---|---|---|
| **军械** | E / D / C / B / A / **S** | 见 §7.2（S 级仅几十件） |
| **公会任务** | E / D / C / B / A / **S** | E = 杂务；**S 级全大陆在世能做的不超过二三十人** |
| **公会执衔** | E / D / C / B / A / **S** | **与任务同级对齐——越级接活 = 找死** |
| **遗存等级** | 同上 | 越高层的遗迹，守卫与代价越重 |

**任务分类学【补】**（参考《猎人》《佣兵天下》）：

- **按对象**：**讨伐**（魔物）· **护送** · **探索**（遗存）· **采集**（灵地/材料）· **护盾 / 净化**（以太污染带）· **护送大人物**（高危）
- **按风险**：E 级 = 跑腿与清剿小型魔物；C 级 = 需小队协作；A 级 = **足以让一座城覆灭的任务**；S 级 = **全大陆不过二三十人敢接**
- **暗单**：公会之外、黑市上的活——**公会默许存在，但绝不写进册子**

### 14.3 各组织的内部结构

- **冒险者公会**：总会 → 大区执衔者 → 城市分部 → 执衔等级（E~S）→ 编外散修
- **圣光圣庭**：教宗 → 枢机主教 → 区域主教 → 司祭 → 执事 → 见习（**教阶决定谁有资格碰圣光系的高阶术式**）
- **城邦三类政体**：**共和**（商人与家族合议）· **王政**（血统）· **商会寡头**（钱）
- **九炉联合体**：**人类席 + 矮人席**共同议政，两族席位对等（这是"合并国家"的制度体现）
- **兽人诸部议会**：**有形式，无约束**——谁打赢听谁的
- **精灵圣林长老议会**：**主族贵族 → 平民 → 奴隶**的三级金字塔

### 14.4 凡俗强者的「准则」（人物塑造的锚 · 参考《蛊真人》《剑来》《诡秘之主》的"扮演法"）

> 蛊真人里每个强者都有不可动摇的**人生准则**；诡秘之主的「**扮演法**」则说明——**获得一种力量，就必须承担一种社会角色，否则失控**。
> **我们的半神有「道」，凡俗强者同样需要。**

**六阶准神各自都有一条铁律**，一旦破例，他的**道心就碎了**——**这才是准神之间真正的克制关系**（不是谁打得过谁，是**谁也不能让对方破例**）。

典型形态举例：
- 「**我从不出手对付比自己弱的人**」→ 他永远只能被动应战
- 「**我接下的活必须做完**」→ 一旦接单就无法回头
- 「**我只在自己的地界里动手**」→ 离开领地他就是个凡人
- 「**我从不用别人的力量**」→ 他无法接受任何传承与仿印

> **这才是"强者"该有的写法：不是数字更大，是限制更多。**

### 14.5 魔物分级与战利品表【v10 补 · 附录B #6】

> 任务分类学（§14.2）已经有了，**但"怪"还没分级**——没有怪的分级，E~S 任务就没有可对齐的对象，冒险者的日常只剩抽象的"更难"。
> **关键一句：魔物不是另一套物种学，它是「以太过浓」的副产物。**

**魔物从哪来**
凡地以太浓度过高，就会**改写活物的形态**——这正是 §6 蚀主的兵源逻辑，也是 §10.4 潮汐三征兆之首「魔物增殖」的机制。
因此 **魔物的等级 ＝ 它被以太改写得有多深**，而不是它本来是什么动物。**一头狼被改到第五层，就不再是狼。**

| 级 | 名号 | 定义 | 典型 | 对应任务 | 主要战利品 |
|---|---|---|---|---|---|
| **E** | **侵蚀种** | 只改写了外壳：体型略大、性情变凶 | 暴躁野猪 · 腐鼠群 · 失心狼 | E · 杂务 | 完整毛皮 · **低阶药料** · 凡铁 |
| **D** | **魔化种** | 改写到脏器：体内开始结出**碎以太结晶** | 鼠潮 · 腐狼 · 瘴鸟 | D | **碎结晶** · 小魔核 · 兽皮符材 |
| **C** | **变异种** | 改写到形态：多肢、再生、能吐以太 | 畸变野兽 · 腐沼巨蜥 · 影豹 | C · 需小队协作 | **中阶魔核** · 骨骼符材 · 瘴囊 |
| **B** | **领主种** | 改写到本能开智：**占一域，会设伏、会记仇** | 兽王 · 巢主 · 雾母 | B | 高阶魔核 · **稀有符材** · **领地内的遗存线索** |
| **A** | **灾厄种** | 改写到自成一域：**它所在之处，以太浓度会自己涨** | 兽潮源头 · 畸变母体 · 沼渊巨口 | A · **足以覆城** | **灾厄结晶**（一件＝一座城一年的符箓原料） |
| **S** | **潮生种** | **非自然存在——只在潮涨年出现，退潮即消失** | 历代记载互不相同 | S · **全大陆不过二三十人敢接** | **只在传说里出现过的东西** |

**三条配套规则**
1. **越级 ＝ 找死**：魔物的 A 级与任务的 A 级**刻意对齐**——一头灾厄种就是一场 A 级任务。**不用解释，读者自己会换算。**
2. **潮涨年，所有魔物整体上跳一级**（§10.4）→ **冒险者的收入随潮汐起伏，粮价随潮汐起伏**——**世界规则自动产生剧情**。
3. **战利品是闭环的一环**：魔核与符材 → **符箓与附魔的原料**（§7.6）→ 装备与任务资格 → **接更难的任务** → 打更高的魔物。
   > **打怪 → 材料 → 装备 → 升阶**这条链在 §14.1~§14.5 里是完整的，**正文不需要再解释"他为什么变强"**。

## 15. 遗存与代价：传承不是白给的【v9 新增 · 参考《蛊真人》《鬼吹灯》《上古卷轴》】

> **三万年积累的上古遗存，不能设计成"打开就有"的宝箱。**

### 15.1 三种遗存形式

| 形式 | 内容 | 难度 |
|---|---|---|
| **洞府 / 遗迹** | 有守卫、有机关、**有连环考验——考的是你这个人，不是你的运气** | 高 |
| **传承** | 需要**资质匹配**，而且**有代价** | 极高 |
| **封存物** | **公会发证才能进**——制度化的、可买卖的 | 中（但要花钱 / 关系） |

### 15.2 代价：越强的遗存，代价越重

我们已经有一个可推广的先例：**负印者借仪器榨取权柄 → 寿命与生命严重损耗**。把这条推成通用规则：

- **下位代价**：付钱、付时间、欠人情、**被某个势力盯上**；
- **中位代价**：**血祭**（献出某种珍贵之物）、**被标记**（接受之后，你在那遗迹前主人面前就不再是秘密）；
- **上位代价**：**寿命**（最硬的通货）、**自由**（替前主人完成某件事）、**道心**（接受一个与你本性相悖的准则 → 见 14.4）。

> **一个世界如果没有代价，它的宝藏就只是数字。**

### 15.3 真相的拼图：历史为什么"可争夺"【参考《诡秘之主》《琅琊榜》】

我们已有结论——「**三万年来没人亲眼见过那场战争，所以历史的真相是可被争夺的东西**」。现在补上**怎么争夺**：

| 真相的载体 | 在谁手里 | 它能证明什么 |
|---|---|---|
| **世界树的"痛感"记录** | 精灵圣林 | 只有模糊的凋零影像，**不记人事** |
| **龙祖神殿的口传** | 龙族（瓦拉克斯） | 龙神睡前的**只言片语** |
| **太古遗存中的残卷 / 器物铭文** | 遗迹、黑市、公会库房 | **最硬的一手证据，但需要拼** |
| **黑暗侧的版本** | 堕落半岛 · 邪教 | 「蚀主是替世界承担代价的圣人」——**流传最广** |
| **教会的版本** | 圣山 · 教会档案 | **刻意抹去了"他是被凡人杀死的"这一段** |

> **→ 真相是散落的四块拼图，每一块都在不同人的手里，而且没有一块是完整的。**
> **谁先拼出来，谁就掌握了三万人的定义权。**

## 16. 三万年大事年表 · 与世界之外【v9 新增 · 参考《冰与火之歌》年表《魔戒》神话层累】

### 16.1 除四大转折之外的大事

| 时期 | 事件 |
|---|---|
| **重建期**（30000–24000 年前） | 神位继任陆续完成；**人类工匠行会**承接传送网与护世大阵的维护；城邦联盟、圣光圣庭建国 |
| **中兴期**（24000–14000 年前） | 文明再攀峰；**九炉联合体**在这一期成形（人类＋矮人合并）；**仿印工艺成熟、验印师出现**；中古遗存层形成 |
| **灾变循环期**（14000–5000 年前） | 四大转折（药奴之痛 / 龙族失序 / 教会孤立 / 联盟崩解）；**数次伪神尝试**——有人试图集齐战魂碎片重铸斗神印，全部失败并留下大量遗迹 |
| **近世**（5000 年前–今） | 第 13、14 次潮汐；旧盛世落幕；**300 年前冒险者公会成立**（整合工匠行会与转运行会） |
| **当代** | 第 15 次潮汐前夜 · 四座空位同时松动 · 光明印复苏 |

> **「伪神尝试」这条值得展开**：三万年里不止一次有人收集碎片、抢夺徽记。**每一次都失败，但每一次都留下了遗迹、帮派与教义——邪教不是凭空出现的，它是三万年失败的沉淀。**

### 16.2 世界之外 · 虚空与位面壁垒

| 项 | 内容 |
|---|---|
| **虚空** | 位面壁垒之外的所在——**黑暗以太的沉积地**。它不是另一个"世界"，而是**没有秩序的所在** |
| **位面壁垒** | 把秩序与无序隔开的那层"膜"。**大寂灭之战把它撕出了无数裂隙**，至今没有愈合 |
| **异次元** | 黑暗徽记被封之处——**与虚空同属壁垒之外**，但那是**人为开辟的封印空间**，不是天然虚空 |
| **铁律第 3 条的真正含义** | 「位面壁垒崩溃」= 那层膜**彻底消失**，届时虚实合一、秩序崩解——**所以必须全员苏醒** |

> **由此补上一个关键的不确定性**：三万年来，没有任何人知道「**崩溃**」的判据是什么。是裂隙超过某个数目？是以太浓度到某个值？还是**根本没人测过**？
> **如果从没有人测过——那么铁律第 3 条从立约起就没被真正触发过，也从来没人知道它该不该被触发。**

## 17. 世界的呈现与玩法【v10 新增 · 检索自写手社区 / 读者反馈 / 四层呈现理论】

> §0–§16 写的全是「**这个世界是什么**」。这一节规定「**读者如何感知它**」。
> 此前三层是**完全空白**的：**何时露出**（冰山的海面在哪）、**怎么打**（力量的玩法）、**怎么活**（角色体验层）。
>
> **三条外部依据**（本轮检索所得）：
> - **写手社区的共识判据**：**「通过情节来讲设定，而不是通过设定来推情节。」**
> - **读者反馈的核心**：买账的不是"他比他强"，而是"**这一招怎么破的**"——力量要有**玩法**，不只是强弱层级。
> - **四层呈现理论**：自然环境 → 社会结构 → 文化表层 → **角色体验**（读者只能通过角色摸到世界）。

### 17.0 总纲 · 三条裁判规则

**① 冰山律 —— 构思 100%，只展示 10%。**
本大纲的每一条规则，**都必须能在正文里找到它「被发现」的那一刻**；找不到的，就留在海面下。
> 大纲越厚，这条越要命：**1000 多行设定里，任何一行没在正文露过脸，它就是负担而不是资产。**

**② 情节律 —— 规则永远不作为旁白出现，只作为角色做决定时的代价出现。**

| ❌ 旁白版（堆设定） | ✅ 情节版（有代价） |
|---|---|
| 相消律是指精神力与生命力互相抵消 | 他左手凝起风刃，右臂的斗气当场散了——**他这才想起师父那句话：你只能挑一只手** |
| 仿印佩戴需五阶以上，否则反噬 | 摊主把木牌贴到他胸口："绿的，放心戴。"**下一秒他咳出一口血**——他才三阶 |
| 传送网载荷有上限，不能传军队 | 命令三天前就到了，**兵还在路上走四个月** |

**③ 自动生成律 —— 一条合格的设定必须能推演出「一个冲突、一个限制、一个代价」。**
三者缺一，这条设定就是装饰品：**删掉它世界不塌，只损失篇幅。**

### 17.1 出场顺序表 · 哪条设定什么时候露

**四幕，每一幕只引入一个"新的世界层面"**（社会层 → 真深层 → 神深层）。

| 幕 | 视角层 | **这一幕露出的设定** | **通过什么事件露（不是解释）** | **这一幕绝不解释的** |
|---|---|---|---|---|
| **一 · 灰尘里的世界** | 城邦（§12 第一层） | 斗气人人可修 · E~S 执衔与任务 · 传送网**存在** · 符箓是日用品 · 寿元与"强者隐世" · 魔物与战利品 | 接一单活；用一张票据走一次传送；集市上买到一张**假**净化符 | **七阶全貌、金字塔数字、任何"史"** |
| **二 · 谁在管这个世界** | 区域（§12 第二层） | 相消律 · 魔法 1/1000 · 灵地归属 · 奴隶制是**全大陆共同制度** · 公会四重命脉 · 九炉的政体 | 同修当场翻车；抢野灵地；公会**三天不发证**让一座城变孤岛 | **徽记、印、半神、潮汐** |

| **四 · 心跳是谁的** | 位面（§12 第四层） | 潮汐＝心跳 · 蚀主死于凡人之手 · 光明印复苏 · 两枚印赛跑 · 虚空与位面壁垒 | 第 15 次潮涨；一份三万年没人读懂的军粮账 | ——（第四幕就是"解释之幕"，**但仍须由角色说出来**） |

**三条硬规矩**
1. **一个名词首次出现时，必须紧跟一次"后果"，而不是一次解释。**（先让读者感到疼，再让他知道为什么疼）
2. **需要解释时，让人物争论，不要让旁白定论。**（两个人说法不一致 ＝ 顺手多埋一块拼图，见 §15.3）
3. **每幕只引入一个新层面**；跨幕之前，上一幕的设定必须已经**被用过至少三次**。

**「永不直说」清单 —— 只让角色去撞，正文里不写定义**

| 规则 | 怎么"撞"出来 |
|---|---|
| 相消律 | 主角强行双发 → 一臂垂下，三天抬不起来 |
| 徽记即认可 | 有人硬抢徽记 → 被自己的手撕开一道口子 |
| 仿印水深 | 集市验印师只说一句："**这枚昨天还是灰的。**" |
| 潮汐＝印的心跳 | 老人说"这次潮来早了一千年，数不对"——**先给直觉，后给真相** |
| 蚀主死于凡人之手 | 三万年的官方战记，与一份军粮账对不上 |
| 六阶只有 250 人 | **一张名册，让读者自己数** |
| 神不能下场 | 神就在那座山上，城里照样饿死人 |
| 战神自碎其印 | 兽人老人讲的版本，和人类史书写的版本完全不同 |

### 17.2 玩法层 · 具名招式与连招（补「打戏」的空白）

> **本大纲此前只有"强弱"，没有"打法"。** 读者反馈原话的落点是：他们想看的是**见招拆招**，不是**数值大小**。

**一场打戏的四段骨架（任何规模都适用）**

| 段 | 做什么 | 世界规则在这里的作用 |
|---|---|---|
| **① 起手** | 亮一个低阶招式 | 让读者**确认阶位**——不报数字，报效果 |
| **② 变招** | 对手用**针对**手段，**不是更强的手段** | 招式之间有**克制关系**，不是只有高低 |
| **③ 代价** | 招式的消耗 / 反噬 / 时限到了 | **谁先撑不住**决定胜负 |
| **④ 收口** | **用世界规则取胜**，不是用数值取胜 | 见 §17.5 的五套模板 |

**招式命名法 · 三类**

| 类型 | 例 | 什么时候用 |
|---|---|---|
| **描述型**（功能即名字，西幻语境最稳） | 裂石击 · 破甲锥 · 静默步 · 三息屏息 | **九成的招式**，读者零成本理解 |
| **传承型**（名字带出处） | 「灰烬庭的第三式」·「渡鸦十二手」 | 要暗示某个组织时——**名字本身就是信息** |
| **代价型**（名字即警告） | 借命斩 · 焚血 · 换手 | 关键场面，**名字先预告代价** |

> ⚠ **禁用纯中文成语 / 网络梗做招式名。** 读者反馈很明确：修仙语境里"成语杀招"是加分项，**放到西幻背景就废了**——**语境不对，好设定也会变成噪音**（详见 §17.4）。

**三条战斗铁律（全部由已有世界规则反推，不是新增设定）**

1. **相消律铁律**：双修者**不能同刻双发**——他的杀手锏是"**切换**"，不是"**叠加**"。于是他的打法天然是**两段式**，被看穿一次就废。
2. **符箓铁律**：**符箓不消耗精神力**（§7.6）→ 这是**凡人对法师的唯一一点**。一个三阶斗者用一叠防护符硬吃一记四阶法术，是这个世界**合法的以弱胜强**。
3. **伪印铁律**：**佩戴即五阶，四阶以下反噬**（§4.3）→ 舞台上**谁敢戴，谁就是全场标靶**；而一个四阶硬要戴，**他先被自己的印打伤**。这一条同时是战斗规则和剧情机关。

### 17.3 日常层 · 角色体验（四层呈现的最后一层，也是此前最空的一层）

> 每条给一个**可直接写进正文的画面**，并注明它**顺带替你交代了哪条规则**——这就是"用情节讲设定"的具体做法。

| 切片 | 画面 | 它替你交代了什么 |
|---|---|---|
| **法师的一天** | 他不点灯——指尖那点光比油灯稳，也比油灯贵；**他省着用，因为精神力用过头会手抖**，而明天还要抄一张阵图 | 精神力的代价（§2.1）、知识垄断（§14.1） |
| **斗气与体力活** | 码头装卸工一跃跳上三层货堆——**他只是个一阶**；真正的分界线不在能不能跳，而在**五阶之后没人再肯干这个** | 斗气人人可修的**社会后果**（§2.3） |
| **集市上的一枚仿印** | 摊主把木牌往客人胸口一贴："灰的，昨天还是绿的，您放心戴。"旁边坐着个**验印师**，只收现钱 | 仿印产业、验印师、佩戴＝五阶（§4.3） |
| **传送网改变了什么、没改变什么** | 信三天到，**人还是走三个月**——所以"去都城"永远是大事，而"都城来的消息"永远已经过时 | 传信不传兵（§9.1）、票价（§9.1 补） |
| **寿命差的一顿饭** | 精灵主人说"明年再办"，人类管事心里咯噔一下——**对精灵是明年，对他已经是一辈子的三分之一** | 寿元阶梯的**情感重量**（§13.1） |
| **潮年** | 潮还没来，粮价先动；老猎人不看天，**看粮价** | 潮汐三征兆（§10.4）、历法（§10.6 补） |

### 17.4 语境校验 · 哪些词在西幻里站得住

> 检索到的读者反馈里有一条被反复强调：**语境不对，好设定也会变成噪音。**

| 词 | 功能 | 西幻读者能否秒懂 | 处理方式 |
|---|---|---|---|
| **公会执衔 / 任务分级 E~S** | 统一分级 | ✅ 能（游戏语境通用） | 直接用，**全书只教一次** |
| **以太结晶 / 战魂碎片** | 货币与材料 | ✅ 能（fantasy 语境通用） | 直接用 |
| **符箓** | 法术的"日用化" | ⚠ 半懂 | **首次出现必须是一件商品**（洁净符、火引符），**不解释原理** |
| **验印师 / 暗单 / 执衔** | 中式行当感最重的三个 | ⚠ 半懂 | **必须给一次功能演示**（§17.3 仿印切片），**绝不给词源** |
| **潮 / 潮数纪年** | 我们独有的纪年 | ❌ 不懂 | **用一次灾变教会读者**——"那是第十四次潮" |
| **印 / 徽记** | 全书核心 | ✅ 能 | 但**绝不与「徽章 / 勋章 / 圣痕」混用**，全书统一「印」「徽记」 |

**三条命名纪律**
1. **一个概念只有一个词。**「徽记」不许同时叫「印记」「徽章」「圣痕」。
2. **首次出现的生词，全书不超过 3 个**（超出就是堆设定）。
3. **行当词只演示、不解释；规则词只解释、不铺陈。**

### 17.5 五套可复用的连招模板（把 §17.2 的四段骨架填实）

| # | 模板 | 组合 | 四段怎么走 |
|---|---|---|---|
| **① 切手** | 双修者 对 单修者 | 斗气起手 → 强行切到魔法 → 吃下切换反噬 | 起手用拳；变招对手封住拳路；代价是切换时**半息空档**；收口**赌那半息** |
| **② 纸盾** | 凡人斗者 对 法师 | C 级防护符 ×3 ＋ B 级铁壁符 ＋ 贴身短兵 | 起手硬吃一发；变招法师换范围术；代价是符**一次性、烧钱**；收口贴身 |
| **③ 假主** | 伪印持有者 | 佩戴伪印 ＋ 引动 ＋ 不敢用真印 | 起手虚张；变招被验印师一句话拆穿；代价是**四阶以下反噬**；收口**逃**而不是打 |
| **④ 阵车** | 小队 对 单体强敌 | 阵旗(B) ＋ 成套符箓 ＋ 三名同阶轮流 | 起手布阵；变招敌人拆阵眼；代价是**有人必须守阵眼不能动**；收口守阵眼的人死或活 |
| **⑤ 借神** | 六阶 对 六阶 | 各自的「准则」（§14.4）＋ 上古共约禁止神下场 | 起手互不先动；变招**谁先破例谁碎道心**；代价是道心；收口**打不起来**——张力全在"谁先违约" |

> **⑤ 是这个世界独有的**：高层战斗的胜负不取决于威力，取决于**谁先打破自己给自己立的规矩**。

### 17.6 退稿自检 · 七条一票否决

| # | 如果出现 | 结果 |
|---|---|---|
| 1 | 开篇 3000 字内出现**大段**历史 / 地理 / 规则 | 读者跳过或弃书 |
| 2 | 一段 2000 字过去，**剧情没推进**，只有设定在涨 | 两张皮 |
| 3 | 某条规则**从未被违反过** | 它没被立起来——**安排一次违反** |
| 4 | 某个角色**没为任何规则付过代价** | 力量无代价 ＝ 无张力 |
| 5 | 同一个概念出现**两个名字** | 立即统一（§17.4） |
| 6 | 一场打戏分出胜负，**但没用到任何世界规则** | 这场戏放在哪个世界都一样 → **重写** |
| 7 | 一条设定删掉后**剧情不受影响** | 它是装饰品 → **删掉** |

> **判据一句话：这个世界必须能自己运转、自己生成故事。**
> 每条规则都能推动剧情、塑造角色、制造冲突——**到这一步，设定才真正活了。**
