① 光明印改到封印处 · 教会的圣地是假的（canon #24）

项原现
光明印的位置圣山宝库 · 三万年无人被认可与黑暗印同封于异次元、以光镇暗三万年——破晓者归寂的方式就是把自己的印留进去当锁；圣山只剩破晓圣盾＋一座空印座
印为什么选不到是印睡着了，还是教会没让它选？不是选不中，是不能（在封印里当锁的印无法回应认可）
教会的姿态守候者（真）公开教义不变（安奉于圣山）；真相不落文字、教宗口传给继任者；所谓「圣战·清勒半岛」＝定期渡海加固封印，渡海要走公会发证 → 教会与公会互握把柄
教内三层认知—教宗（知情）→ 极少数枢机 → 卡西乌斯等（不知情）——狂热派要「指派人选」，而那件事物理上做不到；邪教因此巴不得他越努力越好
潮汐第二根引信印在圣山异动封印里的印被黑暗以太泡了三万年——黑暗是唯一能伤神格的力量，「复苏」不是苏醒，是它在喊疼（与② 同一条规则）
改力—03/04/05/08/09/12/13/14/大纲 ＋ 8 个视图 ＋ mapData/regions

顺手解决的老问题：教会「孤立却刚需」的悖论（审计 A6/A9）；「两枚印赛跑」从抽象变空间事实；蚀主那句「只要光明徽记存在，黑暗就永远不会被真正消灭」从金句变成字面真理。

② 战斗印碎法重写（canon #25）

  • 原：蚀主一击把印「打出裂缝」→ 戈拉赫自行献祭、把有裂纹的印打碎。
  • 现：决战中他把徽记的全部之力贯注进最后一击，第一次真正撕碎了蚀主的防御；黑暗以太顺裂缝灌入，印当场碎裂——他既是主动献祭，也是被黑暗碎掉的（两种情形同时成立）。
  • 连带改写：03 §4.2「印不可毁」的例外从唯一条（自碎）改为唯二条：① 持有者主动献祭；② 被黑暗以太侵蚀——而黑暗印本身毁不掉，因为黑暗以太侵蚀不了它自己（这就是它只能被封的死结）。
  • 仿印的两条产品线（新）：仿印（量产） = 以太结晶 ＋ 碎屑掺入其他材料铸成（掺料正是“仿得像却不是真的”的原因）；高级材料（稀有） = 碎屑直接嵌进魔铠与兵器，与战魂铠碎片在黑市上混在一起 → 寻宝线的难度来源。

③ 卢西恩与艾德里安同为教会圣所出身（canon #27）

  • 原：中央平原古武院出身，师弟艾德里安。
  • 现：圣山教会圣所出身、自幼同门——“他信的不是光明，是赢”变得更狠：嫉妒是从输给同床的兄弟开始的（他把经文背烂了祈祷无回应，隔壁床那个人一开口光就来了）。
  • 连带：11 §14.1 路径③去掉「（卢西恩出身）」；12 §15.3 教会抹掉三件事（凡人杀他 / 他的出身 / 光明印真实位置）；「持炬者」变成字面意义（他本就是举圣火的人）。

④ 第七阶不分双轨 ＋ 斗气永无神位（canon #26）

  • 新增规则：印有权柄属性倾向（03 §4.1 九道本源属性表）——只有内在之力同源者才可能被认可。这是 ④ 的地基。
  • 推论：九道里只有「战斗」是武道本源，而它已碎 → 斗气修行者的绝对上限＝六阶：「人人可修」的大众力量被永久封死在神门之外，而「千分之一」的魔法系守着仅存的成神通道——阶级固化的根源是力量的种类。
  • 新增明文：六阶及以下分双轨，第七阶不分（神阶七则第一则改写为「唯徽记可至 · 且须同源」）；15 速查两行。
  • 顺带：黑暗系是魔法六系之一 → 新蚀主只可能是魔法系，斗气系投黑暗最多做到蚀使。

⑤ 种族三层结构（canon #28）

  • 三层：大本营（核心，外人不入、传送网不接）／混居走廊（内海交互区、外环 27 邦、北陆商路）／跨族公共空间（公会、传送网、冒险小队）。
  • 接入表改写（08 §9.1）：从「谁不接」改为 「核心不接、外围全接」——各族把圣地留给自己，把码头交给世界（精灵外围贸易点、近海海裔口岸、边陲兽人集市、龙涎渡全部接入）。
  • 内海交互区制度化：公会管的不是一座城，是一圈岸线；＋ 四族刚需清单（谁也关不起门 →「闭关是姿态，贸易是命」）。

过程中发现并记录的坑

  1. meta 化：nav/title 写在路由顶层会被 vue-router 静默丢弃——标题不随页面切换。必须写进 meta: { ... }，check.py 已加此检查。
  2. vue-router 5.x 只监听 popstate，不监听 hashchange（源码里 hashchange 计数为 0）：因此不能用「改 location.hash」来驱动导航，必须点击 router-link（内部走 pushState）或走首屏深链。校验脚本据此改用真实点击。
  3. #app 包裹层安全：style.css 只有 * / html / body 级选择器，无 body > 结构选择器，故 <body> 下多一层 #app 不影响任何布局。
