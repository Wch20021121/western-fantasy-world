3. 九道本源 · 与当代神位【v6 核心重写】

3.1 那一代九位的结局

那一代半神，只活下来两个：龙神与风神。 其余七位，都在大寂灭之战中走到了尽头——但他们的死法各不相同，而每一种死法都留下了一件当代事件。

本源真名 · 封号种族结局留下了什么
巨龙阿瑟拉克斯 · 太古龙神龙族存活 · 重伤沉睡龙岛龙祖神殿之下沉睡至今
风凯瑞尔 · 无系者精灵存活 · 本已濒死，被生命神以命相救东境风眼的三万年风暴——里面睡着一个被同族用命换回来的人
光明艾德里安 · 破晓者人类归寂（把光明印与黑暗印一同封入异次元、以光镇暗，随即卸下权柄）光明徽记空悬三万年，对外只宣称「锁于圣山」
战斗戈拉赫·断角 · 百战之魂兽人自碎徽记（主动献祭：最后一击撕碎蚀主防御，印碎于黑暗以太）斗气成为人人可得的力量；神位永缺
生命瑟拉薇尔 · 常青者精灵牺牲（不是战死）把最后的生命传给濒死的风神，救下他后本源耗尽而亡；约 3000 年前由徽记认可的精灵强者继任
水涅露恩 · 潮音之主海裔战死由海裔原种族继任
土沃尔加·磐玺 · 不动者矮人战死由矮人原种族继任
火布罗姆·熔心 · 万炉之主矮人战死熔火宝珠随他崩碎；火徽记就此下落不明
黑暗卢西恩 · 蚀主人类被人类士兵击杀印完好 → 被仅存的三位半神（龙神、风神与尚未归寂的破晓者）封入异次元

那一代的账

  • 存活 2：龙神 · 风神（而风神的命是生命神换来的）
  • 战死 4：水 · 土 · 火 · 黑暗（死于凡人之手）
  • 牺牲 1：生命——她把最后的生命给了风神
  • 归寂 1：光明
  • 自碎 1：战斗——以最后一击献祭，印碎于黑暗以太

所以封印黑暗徽记时，在世的只有三位半神：龙神、风神与尚未归寂的破晓者（光明）。 新一代的生命 / 水 / 土，是战后重建期才陆续被各自的印选定的——这也是为什么「上古共约」由「五位在位半神（两位原班 + 三位新任）」而非「五位旧神」立下。

3.2 战斗之神 · 最后一击与印的碎裂【v15 重写】

他的死不是「被打出裂缝」，而是：他把自己的整个神位，换成了终局的那一击。

  • 决战之中，戈拉赫把战斗徽记的全部之力贯注进最后一击，撕碎了蚀主的防御——诸神围攻近千年，第一次真正打穿他。
  • 与此同时，黑暗以太顺着这一击的裂缝灌入徽记，印在他手中当场碎裂。（黑暗以太是唯一能伤「神格」的力量——见 §4.2）
  • 他是主动献祭的，也是被黑暗碎掉的——两种情形同时成立，这就是「印不可毁」唯一例外的出处。
  • 三重后果：
    1. 他形神俱灭（印碎则神灭，这是铁律）；
    2. 战斗神位从此永缺——这是绝对的，不可能被修复。 碎了就是碎了，没有任何手段能让它变回原来那枚；
    3. 那些碎片散落古战场，成了全大陆斗气的来源——每一块碎片对持有者都是极强的力量来源。

唯一的例外（这才是这条线真正的形状）

集齐所有碎片，可以使它「恢复」——但恢复到的，永远不是原来那个力量。

  • 可以恢复，不能复原：拼回去，它也只是一枚残缺、降级、永远到不了原高度的印；
  • 而且不能用来封神——它已经不再满足"唯徽记可至"中"那枚完整印"的要求；
  • 但仅仅是这样，就足以让人疯狂：一枚打折的斗神之印，对凡人仍是压倒性的力量。

而「集齐所有」这四个字，就是这条线的全部难度

  • 碎片在三万年里被镶嵌、熔铸、传家、打进了兵器、也融进了血脉；
  • 兽人与矮人没有文字，哪有几片，全靠口传；
  • 于是它散到了无法统计的程度——物理上接近不可能。

这条线的张力不是"能不能修好"，而是「永远缺最后几片」。
他把自己的神位，拆成了给所有人用的力量。 而三万年后，人们只记得"斗气是人类的武道"。

3.3 当代神位 · 五在位、四空缺【新增 · 这是全设定的枢纽】

类型神位说明
在位 · 原班（那一代活下来的两个）龙神 · 风神三万年未被替换，仍带伤沉睡在各自的圣地
在位 · 已换代生命（约 3000 年前 · 精灵强者）· 水（海裔）· 土（矮人）印回归无主后自己挑顶尖强者，通常落回原种族领地；三万年间已换过多代
⚠ 与 §10.3 对齐：水、土、以及生命的早先几代都在重建期选定；而生命系的上一任牺牲得最晚、空窗最长，最近这一次（约 3000 年前）落在近世期
空缺黑暗（印封于异次元）· 光明（印与黑暗同封于异次元当锁，三万年无人被认可；教会对外宣称在圣山）· 战斗（印碎，永不可继任）· 火（印下落不明）四座空位 = 四条主线

神位迭代的三条规则【v6.3 改写】

  1. 印自己选人，选的是顶尖强者——本质是「世界的青睐」：符合要求的人，本就会诞生在那一带。
  2. 它常常落在特定种族的领地，但那不是议会选出来的。 议会（精灵的圣林议会、矮人的九炉议会）至多是见证与承认，不是选举——印没有问过任何人的意见。
  3. 生命系由精灵族内强者承接（约 3000 年前那次即如此）；斗神不可继任（印碎）、火神无从继任（印失踪）——这两座空位三万年无法补上。

由此得出的四个种族事实
| 种族 | 当代的神 | 备注 |

|---|---|---|
| 精灵 | 2 位：生命（新任）+ 风（原班） | 精灵是当代唯一有两位神的种族 |
| 矮人 | 1 位：土（新任） | 火神之印下落不明——所以焚天活火山至今无人认领 |
| 海裔 | 1 位：水（新任） | |
| 龙族 | 1 位：龙神（原班） | |
| 人类 | 0 位 | 人类的两道印全空：黑暗死于封印前、光明三万年无人被认可 |
| 兽人 | 0 位 | 斗神自碎——兽人为全大陆把神位拆成了碎片，自己一个也没留下 |

一个几乎白送的剧情设定：人类与兽人是这个世界上"失去神的两个种族"。
而灭世者是人类，斗气之祖是兽人——两个种族都曾离神最近，也都再没能拿到神位。

铁律对当代神位的约束：上古共约禁止半神直接干预凡俗。所以当代五位在位神，一个都不能下场打仗——世界要靠凡人自己撑。而铁律第 3 条又写着：若位面壁垒崩溃，所有半神必须全员苏醒救世。

于是全世界最尖锐的问题变成：谁来判定"崩溃"？谁在拖延这个判定？

⚠「大于」不等于「打不死」。 阶差的具体倍数、六阶被人杀死的配方、半神被杀死的配方，全部见 02_力量体系.md §2.6。
一句话：高阶不是「伤害高」，是「他决定这场仗什么时候开始、什么时候结束」——杀他，就是把这三样夺走。

4. 徽记法则

4.1 徽记本身就是认可

八道本源各凝一枚本源徽记（第九道因卢西恩而生）。它不只是器皿——它的存在本身，就是"世界认可你"这件事的具象。

  • 常规路径：先被本源认可，徽记随之与你同体。
  • 例外的路径：卢西恩。他先吸收了黑暗以太，世界为了回应他，才凝聚出第九枚徽记。

权柄的属性倾向【v15 新增 · 这是「斗气永无神位」的地基】

印挑的不只是「强」，还有「同源」——只有内在之力与该印同源者，才可能被认可。

本源属性倾向对应力量
光明圣光系魔法
黑暗黑暗系魔法
火元素（火）魔法
水潮汐系魔法
生命生命系魔法
土符文与锻附魔法
战斗武道 / 斗气斗气——九道里唯一一道武道本源
巨龙跨系（精神与肉身未曾分化）龙族天赋
风无系特例（凯瑞尔）

于是从战斗印碎掉那一刻起，斗气修行者的神门就永远关上了：当代三座可争的空位（光明 / 黑暗 / 火）全是魔法系本源——「人人可修」的大众力量，反而被永久封死在六阶之下。（推论详见 02_力量体系.md §2.4）

4.2 徽记的性质【修订】

性质内容
不可被毁坏没有任何外力能摧毁它——S 级本源七件与任何一位半神都做不到。例外只有两条：① 持有者主动献祭；② 被黑暗以太侵蚀（黑暗是唯一能伤「神格」的力量）。战斗之神两条全占，是三万年来唯一一例；而黑暗印本身毁不掉——黑暗以太侵蚀不了它自己。这就是它只能被封、不能被毁的死结
持有者死亡 → 回归无主它不会碎，只会脱离死者、保持完好地成为无主之印——这就是为什么蚀主死后，众神封印的只能是一枚徽记而不是一个人
可作为武器增强与自身属性相符的力量。但增幅并不夸张——它不能让凡人变成神，只是让强者再强一档
可以伪造见 4.3
不可强夺见 4.4
不可传承认可不是人的传承，是世界的选择。父传子、师传徒、王传臣，全部无效

4.3 伪造徽记 · 「仿印」【v6.3 重写】

  • 它为什么存在：战斗徽记在大战中碎成无数碎片——凡人的斗气从此失去了可以依靠的增幅凭依。战后，人类工匠与矮人铸造师联手把以太结晶与碎屑铸成「仿印」并量产，专门用来增幅极强的战士。这个产业，是被那枚碎掉的神格喂出来的。
  • 碎片的两条去处（两条产品线）【v15 补】：
    1. 仿印（量产线）——以太结晶 ＋ 战斗印碎屑掺入其他材料铸成：「掺料」正是它仿得像却不是真的原因；
    2. 高级材料（稀有线）——直接把碎屑嵌进魔铠与兵器：昂贵、抢手，是 A~S 级锻造里最抢手的「掺料」。它与百战战魂铠的碎片在黑市上混在一起，谁也分不清哪块是军械、哪块是神格——这正是寻宝线的难度所在。
  • 数量极少——绝不是人人都有，绝大多数人一辈子见不到一枚。所以看见有人佩戴，就会默认他是一位极强的强者。
  • 佩戴 = 五阶及以上：原因不在门规，在物理——仿印的增幅有承受门槛，四阶以下的身体扛不住那股冲击，戴上反而被反噬。「敢戴、戴得住」本身就是五阶以上的证明。
  • 它确实有增幅：对那位战士而言是实打实的（气量、爆发、续航各抬一档），但也仅此而已——没有权柄、无法登神。
  • 真假难分——连神都分不出：量产工艺成熟后，仿印与真徽记在外观上已几乎无法区分，就算一位真正的半神也未必分得清——于是分不清佩戴者是半神，还是五阶强者（两者都扛得住）。
    - 但普通人冒充不了：四阶以下的身体承受不住，戴上当场被反噬——所以街上没人挂这个，「敢戴」本身就是门槛。
  • 「验印师」这一行很尴尬：没有消失，但只剩验低端货、给来历出文书、给城里人一点安慰——真正高端的仿品，谁也验不出来。

4.4 不可强夺 · 与「召回」

不是"你抢不走"，而是"抢了也没用"。

一旦徽记认可过某人，他伸手就能把它召回。 所以任何夺印者都只是替人保管——他可以拿着它走进几千里外的一座城，然后在某个夜里发现手里空了。

4.5 负印者

未获认可、却长期持有一枚徽记的人，称为「负印者」。

  • 徽记在他手里毫无作用——纯是持有；不排异、不压垮他。
  • 若借特殊仪器强行榨取，可以抽出一丝权柄：作用微乎其微，但代价极重——寿命与生命会受到严重损耗。

负印者是一群可怜人：他们比谁都清楚自己手里拿的是什么，也比谁都清楚自己用不了。

四座空位 = 四条主线

  1. 黑暗印：封在巨洞之下，邪教想把它捞出来，让它再认一个「蚀主」。
  2. 光明印：与黑暗印同封于异次元，压了黑暗三万年——不是选不中，是不能（在封印里当锁的印无法回应认可）。而教会对外宣称它在圣山。
  3. 战斗印：碎成了碎片，散在古战场——理论上可以重铸，三万年无人做到。
  4. 火印：没有人知道它确切在哪。 位置早在神话流传中就已失真——但不是全无线索：少数部落一直握着它的大致方位，像一张口传的寻宝图。
    　而这些线索从不外传，兽人与矮人又没有文字，记忆必然随代际流失。时间越久，知道的人越少——到今天，只剩一个地名和一个传说。

而四座空位里，两枚「完整」的印在同一个地方——异次元的封印里。谁想动它们，就得先穿过半岛、绕过公会的发证权、再扛住三万年没换过班的教会秘密。

4.7 以太潮汐 = 被封徽记的心跳【新增 · 由本轮推导】

黑暗巨洞之下的那枚印，三万年没有沉下去。它在呼吸。
每一次以太潮涨，都是黑暗徽记的心跳。

  • 周期约 2100 年一次，至今 14 跳（最近一次约 300 年前）。
  • 第 15 跳本该再等 1800 年，现在就到了。
  • 与此同时，封印里的光明徽记也出现「复苏」征兆——教会对外仍叫它「圣山的印」。
  • 它为什么会异动：黑暗以太是唯一能伤「神格」的力量（§4.2）。这三万年，光明印一直在被黑暗缓慢侵蚀——「复苏」不是苏醒，是它在喊疼。若它被泡穿，封印就不再是锁。
  • 两枚沉睡三万年的印正在赛跑——它们各自想认一个什么人，而那个人就是这个故事的主角。
