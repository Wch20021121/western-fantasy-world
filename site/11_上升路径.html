14. 上升路径 · 组织内部 · 强者的准则【v9 新增 · 参考《全职高手》《猎人》《佣兵天下》】

14.1 普通人的五条路

路径怎么走特点
① 公会冒险者接任务 → 攒资源 → 升执衔 → 接更难的任务最主流，也是唯一"不靠投胎"的一条
② 城邦军队军功换资源与制式装备；四阶以上可入「镇国」编制稳定、慢、受制于城邦
③ 学院 / 古武院正统师承、系统训练要天赋，也要钱——它筛的就是这两样；卢西恩不出自这里——他与艾德里安同为教会圣所出身（见 05 §5）
④ 商会 / 行会锻造师、符箓匠、药师不靠打架也能走到四阶——技术型上升通道
⑤ 野路子黑市、战魂碎片、仿印、奴隶赃物最快也最危险，而且到四阶就撞上制度的墙

五条里只有第一条是「公平」的。——这就是冒险者公会存在的根本理由，也是它能维持「中立」的民意基础。

14.2 统一分级制：一套 E ~ S 贯穿全书

军械、任务、执衔、遗存，用同一套字母——读者只需学一次。

用途分级说明
军械E / D / C / B / A / S见 §7.2（S 级仅几十件）
公会任务E / D / C / B / A / SE = 杂务；S 级全大陆在世能做的不超过二三十人
公会执衔E / D / C / B / A / S与任务同级对齐——越级接活 = 找死
遗存等级同上越高层的遗迹，守卫与代价越重

任务分类学【补】（参考《猎人》《佣兵天下》）：

  • 按对象：讨伐（魔物）· 护送 · 探索（遗存）· 采集（灵地/材料）· 护盾 / 净化（以太污染带）· 护送大人物（高危）
  • 按风险：E 级 = 跑腿与清剿小型魔物；C 级 = 需小队协作；A 级 = 足以让一座城覆灭的任务；S 级 = 全大陆不过二三十人敢接
  • 暗单：公会之外、黑市上的活——公会默许存在，但绝不写进册子

14.3 各组织的内部结构

  • 冒险者公会：总会 → 大区执衔者 → 城市分部 → 执衔等级（E~S）→ 编外散修
  • 圣光圣庭：教宗 → 枢机主教 → 区域主教 → 司祭 → 执事 → 见习（教阶决定谁有资格碰圣光系的高阶术式）
  • 城邦三类政体：共和（商人与家族合议）· 王政（血统）· 商会寡头（钱）
  • 九炉联合体：人类席 + 矮人席共同议政，两族席位对等（这是"合并国家"的制度体现）
  • 兽人诸部议会：有形式，无约束——谁打赢听谁的
  • 精灵圣林长老议会：主族贵族 → 平民 → 奴隶的三级金字塔

14.4 凡俗强者的「准则」（人物塑造的锚 · 参考《蛊真人》《剑来》《诡秘之主》的"扮演法"）

蛊真人里每个强者都有不可动摇的人生准则；诡秘之主的「扮演法」则说明——获得一种力量，就必须承担一种社会角色，否则失控。
我们的半神有「道」，凡俗强者同样需要。

六阶准神各自都有一条铁律，一旦破例，他的道心就碎了——这才是准神之间真正的克制关系（不是谁打得过谁，是谁也不能让对方破例）。

典型形态举例：

  • 「我从不出手对付比自己弱的人」→ 他永远只能被动应战
  • 「我接下的活必须做完」→ 一旦接单就无法回头
  • 「我只在自己的地界里动手」→ 离开领地他就是个凡人
  • 「我从不用别人的力量」→ 他无法接受任何传承与仿印

这才是"强者"该有的写法：不是数字更大，是限制更多。
