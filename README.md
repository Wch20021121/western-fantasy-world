## 核心设计（一句话版）

- **没有魔神**：灾难来自**黑暗以太的侵蚀**，它不恨你，只是不认得秩序。
- **斗气人人可修（90%），魔法看天赋（1/1000）**——这是世界最根本的分工。
- **蚀主不是被封印的，是被一个无名的人类士兵杀死的**——众神封印的，只是一枚毁不掉的徽记。
- **阶差是「速率差」，不是「伤害阈值」**：低阶的攻击**从来不是 0，只是被打折**——所以**人数＋准备**是合法的胜利方式，半神**强，但可以被战胜**。
- **半神的代价比凡人更重**：神位是荣耀，也是枷锁。
