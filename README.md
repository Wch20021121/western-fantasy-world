# 埃拉西亚大陆 · ERATHIA

一套完整的西方奇幻世界观设定，包含**力量体系、战力规则、历史年表、地理势力**与配套的可浏览 **Vue 站点**。

> 当前版本：**v13** ｜ 枢纽文档 `docs/大纲.md` ｜ 站点工程 `web/`（**Vue 3 + Vite**）

---

## 快速开始

```bash
# 【日常】拉代码 + 一键挂载（首跑自动装依赖 → 构建 → 挂 8000）
git pull && sh run.sh

# 【自测】本地冒烟测试 127.0.0.1:8001，测完自动停，不碰正式服务
sh test.sh

# 【开发】热更新 → http://127.0.0.1:8000/
cd web && npm install && npm run dev

# 【运维】sh run.sh stop | status | log
# 【换端口】PORT=9000 sh run.sh   （或直接改 run.sh 里的 PORT=8000）

# 从枢纽文档读起（推荐入口）
open docs/大纲.md
```

> **依赖与构建产物不入库**（`node_modules/`、`dist/` 见 `.gitignore`）；
> 入库的是 `package.json` + `package-lock.json` + `src/` + **启动方法**。

### 🌐 Vue 站点（`web/src/` · 11 个视图）

同一套内容的可浏览版本，**Vue 3 + Vite + vue-router（hash 路由）**，全站共享 `src/assets/style.css`。原静态站点整体存档在 `temp/site_static_v13/`（工作痕迹，不删）。

```
web/src/
├─ router/routes.js        ★ 路由表 = 全站唯一真值（加页面只改这里）
├─ router/index.js         hash 模式 · 换页回顶 · 标签标题同步
├─ components/SiteNav.vue  共享导航（由路由表自动生成，11 项）
├─ assets/style.css        全站样式
└─ views/
    HomeView.vue          首页 · 目录 · 核心亮点
    WorldView.vue         世界本源        PowerView.vue      力量体系 ★ 含 §2.6 战力规则
    RacesView.vue         种族            FactionsView.vue   势力
    GeographyView.vue     地理            HistoryView.vue    战史·时间线
    ArmamentsView.vue     联军军械        CharactersView.vue 半神与人物
    PresentationView.vue  呈现与玩法      GlossaryView.vue   术语表
```

> **路由用 hash 模式**（`http://host:8000/#/power`），纯静态托管即可运行，**无需服务端 rewrite**；
> 首屏只加载 `index + vendor`，各页 JS **按路由懒加载**。换页自动回顶、标签标题随之切换。

**🗺 大陆地图与区域详情页（数据驱动，零依赖）**

| 文件 | 职责 |
|---|---|
| `src/data/mapData.js` | **大陆底图唯一真值** —— 11 个区域的形状 / 标注 / 悬浮卡 / 航路 / 图例。改坐标、改地名只改这里 |
| `src/components/ContinentMap.vue` | 按数据递归渲染；**hover 区域高亮 ＋ 跟随鼠标的悬浮卡 ＋ 点击进入该区详情页** |
| `src/data/regions.js` | **11 区详情唯一真值** —— 关键事实 / 势力划分 / 叙事钩子 / 区域子地图（canon 取自 `docs/08 §9`） |
| `src/views/RegionView.vue` | **一个组件服务 11 个区域** → `/#/geography/<slug>`，上一区 / 下一区互跳，未知 slug 走 404 兜底 |
| `src/components/RegionMap.vue` | 区域内部细分图（势力分区 + 点位标记） |
| `src/lib/svgNodes.js` | SVG 节点树 → vnode，**底图与子地图共用**，不复制第二份 |

> **节点格式统一**为 `{t:'标签', a:{属性}, c:'文本'|[子节点]}` —— 属性名与 SVG 规范一致，Vue 原样透传。
> `check.py` 会**交叉校验「地图上的每个区域都有详情页」**（防点击 404）与区域版式字段完整性。
> 顶栏导航**只有 11 项**：区域子页不带 `meta.nav`，不进顶栏（进入后「地理」仍保持高亮）。

## 核心设计（一句话版）

- **没有魔神**：灾难来自**黑暗以太的侵蚀**，它不恨你，只是不认得秩序。
- **斗气人人可修（90%），魔法看天赋（1/1000）**——这是世界最根本的分工。
- **蚀主不是被封印的，是被一个无名的人类士兵杀死的**——众神封印的，只是一枚毁不掉的徽记。
- **阶差是「速率差」，不是「伤害阈值」**：低阶的攻击**从来不是 0，只是被打折**——所以**人数＋准备**是合法的胜利方式，半神**强，但可以被战胜**。
- **半神的代价比凡人更重**：神位是荣耀，也是枷锁。
