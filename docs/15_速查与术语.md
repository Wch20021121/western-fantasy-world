## 阶差与击杀成本【v12 新增】

> **权威出处：[`02_力量体系.md`](./02_力量体系.md) §2.6。** 这里只放数字。

| 项 | 值 |
|---|---|
| **凡俗每阶速率差** | **约 6×**（有效杀伤速率，**不是伤害阈值**） |
| **跨一阶** | 6× → **6~10 人** ＋ 阵法 ＋ 先手 |
| **跨两阶** | 36× → **40~80 人** ＋ 锁退路 |
| **跨三阶** | 200× → **300~500 人** ＋ 阵法 ＋ 破防 |
| **跨四阶** | 1300× → **1500~3000 人** ＋ A 级禁制 |
| **跨五阶** | 7800× → **约一支万人军团** ＋ S 级破防 ＋ 半日消耗 |
| **六阶 → 七阶** | **约 30×（质变）**——神阶不是第七级台阶，是换一种存在方式 |
| **第七阶的双轨** | **不分战士/魔法**；印须同源，九道里唯一武道本源（战斗）已碎 → **斗气系永无神位，绝对上限＝六阶** |
| **杀一名六阶** | 按最高阶算：五阶 ≥10 ｜ 四阶 ≥50 ｜ 三阶 ≥300 ｜ **常规军 ≈ 一万人**；**＋ 1 件 S 级或 ≥5 件 A 级 ＋ A 级传送禁制 ＋ 半日消耗** |
| **杀一名半神** | **六阶 30~50 名** ＋ **≥3 件 S 级** ＋ **预设封印场域** ＋ **以年计的消耗**（通常还要**另一位半神**） |
| **对等（拖住半神）** | 约 **30 名六阶** |
| **战胜半神 · ① 击败/逼退** | **数十名六阶** 或 **一支有 S 级压阵的军团**——只须「让他不划算」 |
| **战胜半神 · ② 重创/沉睡** | ① 基础上 ＋ **≥1 件黑暗系 S 级**（打出不可逆的**本源创伤**） |
| **战胜半神 · ③ 杀死/归寂** | **§2.6.4 完整配方**（六阶 30~50 ＋ ≥3 件 S 级 ＋ 封印场域 ＋ 以年计） |
| **代价** | 杀六阶：**伤亡三成以上，至少折一名五阶**；杀半神：**参与者折损过半是常态** |

**两条交叉自洽（都来自既有 canon，不是新造的数）**
- 「**一头伪半神 ≈ 一支万人军团**」→ 反推凡俗每阶 **6×**，一阶对六阶 **6⁵ ≈ 7800 ≈ 万人** ✓
- 「**一位半神 ≈ 数十头伪半神**」→ 杀半神需 **30~50 名六阶** ✓
