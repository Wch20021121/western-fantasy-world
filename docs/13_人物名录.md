## 当代人物（名皆可改）

| 人物 | 身份 | 钩子 |
|---|---|---|
| **「无面者」格里安** | 堕落半岛 · **蚀使** | 从不以真面目示人——见过他真容的人都成了他的人。他传达的"蚀主的意志"**其实是一枚印的意志** |
| **教宗 瓦尔登三世** | 教会 · 守序温和派 · **知情人** | 他守的从来不是一枚印，是**「圣山是假的」这句只能口传的秘密**——每一代只说给继任者听。**他的难题不是「为什么三万年选不中」，是「我还能瞞多久」** |
| **大审判官 卡西乌斯·索恩** | 教会 · 狂热十字军派 · **不知情者** | 主张教会必须**指派人选**继承光明徽记——一旦成真，教会就从守候者变成造神者。**而他根本不知道印在哪——他主张的那件事，物理上做不到** |
| **总会长 赛琳·多恩** | 冒险者公会（五阶） | 把三重垄断经营成大陆真正的权力中心 |
| **议长 艾露薇丝** | 精灵圣林长老议会 | **生命之神的见证者**——上一任印选时由她以议长身份见证；这一次若印再选，议会能做的仍是**见证，不是选择** |
| **锻炉长 邦多·煤须** | 矮人九炉议会 | 每天去地心看一眼现任土神；另外，**焚天火山那枚印，他找了六十年** |
| **瓦拉克斯** | 龙族 · 最年长之龙（约 4700 岁） | **他不是龙王——龙族没有王。** 但他守着句**口传**——三万年前那位龙神睡下去之前的最后一句话 |
| **潮语者 涅拉** | 海裔 · 深海城邦 | 现任水神的传话人 |
| **（待定）一位 T4 准神** | 各势力之外的第六阶强者 | **金字塔的腰**——凡人的天花板，也是主角最可能对标的那一档 |
