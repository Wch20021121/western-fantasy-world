## 9. 大陆规模与地理

**星球**表面积约 **10 亿 km²**（地球两倍），半径约 9000 公里；全球陆地约 **3 亿 km²**（地球陆地两倍）。
**主大陆东西跨度约 30,000 公里、南北约 24,000 公里**——是地球直径的 **2.3 倍**。已开化区域约 **1.5 亿 km²**，**人口约 30 亿**（密度约 20 人/km²，因斗气普及与低阶生命药剂而高于同技术水平的地球）。

**距离被劈成两层**：节点之间文书数日可抵大陆另一端；**节点之外仍以月计**；而**军队永远不会被传送**（载荷上限 →「传信不传兵」）。

| # | 区域 | 关键内容 |
|---|---|---|
| ① | **人类中央平原** | 三面接壤主大陆诸族、一面朝内海 |
| ② | **灰铁群山**（**正北**） | 矮人九炉；地心殿堂（**现任土神** + 大地磐石玺） |
| ③ | **精灵圣林**（东部） | 世界树之枝；**现任生命神**居于此 |
| ④ | **兽人诸部荒原**（**内海西南岸**） | **焚天活火山**——万炉之主的坟；**火徽记下落不明**，传闻埋在这一带 |
| ⑤ | **圣山 · 圣光圣庭国**（**南方 · 正对堕落半岛**，隔海峡相望） | 破晓圣盾 ＋ 一座**空印座**（对外宣称光明徽记锁于此处）；**实则光明印与黑暗印同封于异次元当锁**——教会朝圣渡海，实为加固封印 |
| ⑥ | **东境 · 风眼** | 大陆东海岸外一片**三万年不散的风暴**——**原班风神**重伤沉睡于此 |
| ⑦ | **堕落半岛 · 黑暗巨洞**（西南外海） | 外围为**符文禁区**，唯一通行路径由公会发证；**巨洞之下就是黑暗徽记** |
| ⑧ | **上古战场（主岛 + 群岛链）** | **东段残岛链扼住内海咽喉**；战魂铠碎片与**斗神印的万千碎片**散落于此 |
| ⑨ | **龙族龙岛**（东北） | 龙脊雪峰·龙祖神殿；**原班龙神**沉睡于殿下；大陆一侧的**龙涎渡**是龙货集散地（龙人原料的源头） |
| ⑩ | **深海宫殿**（南部深海） | 沧澜潮音珠；**现任水神**居于此 |
| ★ | **誓约之地**（大陆中央 · 内海西岸） | 中立缓冲带；公会总部；**内海交互区的中心** |

**内海交互区 · 公会管的是一圈岸线，不是一座城【v15 新增】**

> 围绕内海的这一圈，是**四族共用的交互区**：**人类、精灵、兽人、海裔**在这里交易、通婚、争执、被拍卖。**它属于冒险者公会**——公会不是「管着一座城」，是**管着一圈岸线**（誓约之地是这段岸线的中心）。
> - **公会提供什么**：中立法律、票据与通行印、担保与仲裁、拍卖行与黑市的秩序（隔街并存）；
> - **各族带来什么**：下方的「刚需清单」——**谁也关不起门**；
> - **所以这里既是最文明的地方，也是最无法无天的地方**：同一栋楼里，上层是五族的调解庭，下层是奴隶拍卖行。

**刚需清单 · 为什么谁也关不起门**

| 谁 | 只有它给得了的东西 | 离了它就没了 |
|---|---|---|
| **精灵** | 生命魔法的真治愈（**唯一**） | 重伤员、药剂、延寿 |
| **教会（圣光）** | 净质——对黑暗畸变**百分百特攻** | 净化、抗蚀 |
| **人类** | 阵法 / 回路 / 文书 / 工程 | 传送网、器械、账簿 |
| **矮人** | 以太赋形的锻造 | 兵器、斗铠、符文底座 |
| **海裔** | 海路与潮汐材料 | 跨海贸易、深海药材 |
| **兽人** | 战兽、兽皮符材、战魂碎片边角料 | 符箓原料、黑市硬通货 |

> **六样刚需，没有一件能自己造齐** → **闭关是姿态，贸易是命。** 这才是「各族交流互通」的物理基础——不是谁比谁大度。

### 9.1 大陆传送网【v6.1 新增】

> **大寂灭之战留下了四件遗产**——**七件 S 级兵器**、**黑暗巨洞上的封印**、**大陆护世大阵**、**大陆传送网**。

**怎么来的**：战争第二百年，联军需要在**半岛前线**与**各族后方**之间调动军队、补给与伤员，普通行军来不及。于是——**八位在世的本源半神（光明·巨龙·生命·战斗·风·火·水·土）各出本源之力，人类工匠具体施工**，符文底座来自矮人的**以太赋形**工艺，从誓约之地向外辐射，把大陆的主要城邦串成一张网。<br>**八道权柄同时供能，这张网才覆盖得了整片大陆。**<br>**为什么施工的是人类**：战时各族精锐都在前线流血，只有人类城邦联盟的工匠行会能拿出成建制的工程队——**于是图纸、口诀、阵图，全在人类手里。**

**战后交给谁**：半神全部归隐沉睡，**但人类可以复建**——三万年来人类工匠一直在钻研阵图，**现代人类已经掌握复建技术**，各城邦的自建线遍布大陆。<br>只是有**质量分层**：半神亲手造的**原始节点**载荷高、稳定、能跨洋；人类复建的**支线**更脆、更慢、更贵。而维护与调度最初由**人类工匠行会**执掌（公会的前身），**约 300 年前被整合为冒险者公会。**<br>**各族为何不研究**：各族**圣地**不接——精灵闭林、龙族拒绝、兽人王庭不服管、深海无法布设（**但各族外围商镇全都接**，见「谁接入」）；矮人提供符文底座，但**阵法不在他们手里**——**人类凭这套技术成了大陆的工程垄断者**，这是「枢纽种族」的第三个支柱（前两个：双系并修、地理居中）。

**六条硬规则**
1. **只能点对点**——只能在既定节点之间传送，无法任意坐标；主干线路是固定的，**战略要冲都在路线上**。
2. **有载荷上限**——重量与人数都有限，**军队无法整军传送**，只能走信使、补给、小队与伤员 → **「传信不传兵」**。
3. **耗以太**——每次启动都烧以太，账面由公会结算。
4. **需凭证**——凭公会票据或通行印才能启动，**公会不发，你就走不了**。
5. **技术在人类手里**——图纸与口诀出自战时的人类工匠行会，三万年由他们及其后人复建、扩容；**各族圣地不接**（矮人只有符文底座）。
6. **质量分层**——**原版主干**（半神所造：稳、快、重）vs **复建支线**（人类所造：脆、慢、贵）。真正值钱的永远是主干上的那几个节点。

**谁接入、谁没有 · 「核心不接，外围全接」【v15 改】**
- **不接入（核心 / 圣地）**：**精灵圣林**（闭林的物理保证）· **龙岛**（龙族拒绝）· **深海宫殿**（无法布设）· **兽人部族王庭**（不服管）· **圣山圣库区**（教会教规）· **堕落半岛**（符文禁区）
- **接入（外围 / 商镇 / 走廊）**：人类城邦联盟 · 矮人九炉与商路节点 · **精灵外围贸易点与游学商站** · **近海海裔口岸** · **边陲兽人集市** · 龙岛对岸的**龙涎渡** · **誓约之地（中央枢纽）** · 公会各地分部
- **一句话**：各族把**圣地**留给自己，把**码头**交给世界——这正是「**大本营 ＋ 混居走廊**」的物理实现（见 `07` §8）
- **堕落半岛没有传送阵**——那是符文禁区，所以打进去永远只能走海路

**传信不传兵，大战到底怎么打【v13 补漏洞】**

> **漏洞**：军队不能传送，那大陆级的战争、兽潮的防守怎么办？
> **补法**：**「远水救不了近火」，这本身就是这个世界的常态，也是张力的来源。**

1. **本地城防先顶**——兽潮 / 入侵来了，**先由本地的城防法阵 ＋ 守军 ＋ 征召的一二三四阶平民**顶住（见 `02_力量体系.md` §2.6.3「城邦怎么防六阶」）。
2. **援军走陆路，以「月」为节奏到**——传送网只送**信使、军官、死士小队、补给**，**大军永远在路上**。
3. **所以「援军还有三个月」就是这个世界最普通的绝望。**

> **这一条反过来解释了三件事**
> · **为什么城邦必须自治、各自养兵**（`09_势力与政体.md` §11「47 邦各养各兵」）——真有事时，指望不上别人；
> · **为什么公会调度权是命脉**——它决定**哪座城的求救信先送出去**；
> · **为什么兽潮能攻城掠地**——**不是打不过，是主力永远在路上。**

**票价与管制【v10 补 · 附录B #10】**

> 一张网光有规则还只是"技术"——**加上票价和证件，它才变成"权力"。**

| 环节 | 怎么收 | 效果 |
|---|---|---|
| **票价** | 按**里程 ＋ 载荷**计，用**以太结晶**结算；人比信贵得多 | **信三天到，人走三个月** →「口信」成了一门正经生意 |
| **常客票** | 行商、公会编内、军务有**包年票** | 有票的人是**大陆上最快的那批人**；没有票的人不是 |
| **管制三证** | **通行印**（身份）· **货引**（报关）· **公会票据**（默认凭证） | 三证缺一，**节点不启动** |
| **黑名单** | 公会可对**个人 / 货种 / 整座城邦**挂黑 | 挂了黑**你只能走路**——对边陲城邦等于死刑 |
| **禁运名单** | 大宗奴隶 · 半岛产一切 · **未鉴定上古遗物** · 超量以太结晶 | **于是走私永远走海路**——半岛那条走私线由此存在 |
| **新建审批** | 自建支线的**图纸需报公会备案** | **入网即受管**（§11）——备案制让"技术扩散"仍在公会眼皮底下 |

> **票价 ＋ 三证 ＋ 黑名单 ＋ 禁运 ＋ 备案 ＝ 五道闸。**
> **公会不需要养军队——它只需要决定谁的信今天能到。**

**它给公会的权力，是所有里最硬的一条**
公会握着的不止是悬赏、任务、治疗与半岛发证权——**它握着整个大陆的交通命脉**。**它可以切断任何一座城邦的传送**：切断三天，那座城就变成孤岛——商路断、援军断、消息断、药材断。
> 于是「中立」有了新的读法：**不是它没有力量，是它选择不把线拔掉。**

**当代的引信之三 · 这张网三面受敌**
> ① **垄断被稀释**——三万年技术扩散，各城邦自建线越来越多，公会正从「**唯一**」退化成「**最大**」；
> ② **潮汐会让全网失灵**——第 15 次潮涨时以太浓度剧变，**无论公会的线还是自建的线，一起过载**；
> ③ **邪教在切断它**——切线、毁节点，不需要攻城，只要让路断掉。
> **公会手里的治疗与半岛发证权可以被人绕开，只有这张网绕不开——而它正同时被稀释、被超载、被破坏。**

**军事上的命门**：当代**五位在位神**分居的圣地（龙岛雪峰 / 东境风眼 / 精灵圣林 / 深海宫殿 / 灰铁地心）就是五道世界级防线——而**上古共约禁止他们直接出手**。**神就在那里，却不能下场。** 这是全设定最尖锐的一条张力。

## 13.3 灵地地图：最浓的以太都被人占着（原 §13.3 · 迁入本文件）

| 灵地 | 属性 | 归属 | 凡俗能否使用 |
|---|---|---|---|
| 精灵圣林 | 生命 | 精灵（闭林） | **否** |
| 灰铁地心 | 土 | 矮人（地心殿堂） | **否** |
| 深海宫殿 | 水 | 海裔 | **否** |
| 东境风眼 | 风 | 风神（沉睡） | **否** |
| 焚天活火山 | 火 | 无人（绝地） | **否**（物理不可达） |
| 古战场 | 战斗残留 | **公会发证** | **半**（付费 / 凭证） |
| 誓约之地 | 混合 | 公会（自治领） | **半**（付费） |
| **野灵地** | 混杂 | **无主** | **是 —— 唯一能抢的** |

**于是冲突的主战场一目了然**：各族、公会、宗门、黑市、邪教——**抢的从来不是宝物，是「无主的散灵地」。**
而它天然分布在外围、废弃地带、灾变遗址——**与怪物潮、与遗存、与奴隶贸易重叠。**

**野灵地的具体分布【v10 补 · 附录B #7】**
野灵地**不是随机的**，它只出现在三种地方——**而这三种地方恰好都是"没人管"的地方**：

| 类型 | 成因 | 典型位置 | 与什么重叠 |
|---|---|---|---|
| **灾变遗址型** | 潮涨 / 大战打散了原本的灵脉，浓度过高又无主 | 近世遗存废墟（§10.5）· 上古战场外围 | **魔物 · 遗存** |
| **边陲废弃型** | 各族都不要的边角：荒原尽头 · 群山缝隙 · 沼泽 | 兽人荒原北部 · 灰铁群山外缘 · 内海西岸滩涂 | **奴隶贸易 · 黑市** |
| **封印渗漏型** | 靠近巨洞 / 封印，以太被"漏"出来 | 堕落半岛外围三处无名礁 · 圣山东麓 | **邪教 · 畸变** |

**数量（建议值，可调）**：全大陆已登记的野灵地约 **200~300 处**；够得上"修行福地"级别的 **不超过 40 处**；**同时无主且可用的不超过 10 处**。
> **「那十处」就是全大陆所有散修、宗门、黑市、邪教在抢的那口锅**——§13.3 说的"抢的不是宝物"，落到数字上就是这十个名额。
