## 13. 修行的现实：寿元、瓶颈与成本【v9 新增 · 原 §13（13.3 灵地地图已迁至 `08_地理与传送.md`）】

### 13.1 寿元阶梯：四阶与六阶是两道坎

**基础寿命是种族性的，修行能突破——但要到四阶才开始明显跳档。**

| 阶 | 人族寿元 | 阶段 |
|---|---|---|
| 一阶 淬体 / 感知 | **100–120** | 与常人无异（斗气本身已带来轻微延寿） |
| 二阶 凝气 / 引灵 | 110–140 | 微延 |
| 三阶 罡气 / 术式 | 130–170 | 开始超出常人 |
| 四阶 战魂 / 领域 | 160–220 | **第一道跳档** |
| 五阶 斗域 / 大魔导 | **200–250** | 突破凡物上限（即「高阶法师 200+」） |
| 六阶 本源（准神） | **400–600** | **第二道跳档：触及世界底质** |
| 七阶 神阶 | 与本源同寿 | |

**各族在其基础上同比放大**：兽人基础 300–500 → 高阶可破千；矮人 400–500 → 高阶更长；精灵 1500–2500 → 高阶可至近万；龙族 3000–5000 → 古龙可能破万。

**⚠ 一条必须守住的天花板**：**没有任何凡俗修行者的寿命能接近三万年。** 即便是龙族六阶的绝对上限（约一万年），**也只有那场战争的三分之一**。
→ **所以「无人记得大寂灭之战」这条核心设定，不依赖任何前提，天然成立。**

**寿元带来的直接红利（很值钱）**：

> **六阶那 250 人里，一大半是活了几百年、上千年的老怪物。**
> 所以「**公开可查的不过四五十人**」不是因为他们少，而是因为——**活得够久的人，早就退出了世俗竞争。**
> **六阶的"隐世"，是寿元的副产品。** 这条同时解释了：准神为什么难找、各族"镇族强者"为什么从不出手、以及为什么他们的传说都模模糊糊。

### 13.2 三重门：五阶为什么只有 150 个能上去

**不是天赋不够，是「门」就那么几扇，而且都被人占着。**

| 门 | 内容 | 为什么稀缺 |
|---|---|---|
| **① 地利 · 灵地** | 必须在**以太富集或有本源残留**之处"沉下去"，才能撬动世界底质 | **最浓的灵地全在神的圣地与禁区里**（见 13.3） |
| **② 材料 · 资源** | 突破所需的消耗品：淬骨锻体材料、以太结晶、以富集地为引的药剂 | **贵，且供不应求** |
| **③ 机缘 · 触底** | 需要一个"真正沉到底"的契机：古战场的本源残留、绝地的濒死、或他人的传承 | **求不来** |

> **这三重门，就是这个世界所有冲突的来源。** 人不是打不过谁，是**进不了那扇门**。


### 13.4 修行的日常成本

| 体系 | 日常成本 | 谁付得起 |
|---|---|---|
| **斗气** | **血气损耗需食补与药浴**（大量肉食、锻骨药材）；淬体要**锻体材料**；高端要**战魂碎片** | 贵族、军中、公会编内 |
| **魔法** | **精神力恢复靠冥想与时间——这钱买不到**；施法需符纸媒介；高阶必须**常驻灵地** | 有闲的富人、法师塔、教士 |
| **符箓 / 阵** | 原料：兽皮、矿粉、以太结晶 | 行会、商会 |

> **结果：斗气养不起的人练不动，魔法没时间的人练不动。** 「人人可得」讲的是**门槛**，不讲**钱包**——这正是大多数人停在一阶的真正原因。

**货币【补 · 建议】**：**金银为日常通货；大宗结算用「以太结晶」；黑市顶级硬通货是「战魂铠碎片」。**
