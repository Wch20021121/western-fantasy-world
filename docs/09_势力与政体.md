### 人类城邦联盟 · 「数十城邦」是怎么分的【v10 补 · 附录B #9】

> 「数十城邦」此前只是一个形容词。**没有骨架，联盟就只是一个背景音。**

**定数（建议值）：47 座城邦**——正好卡在"数十"上，也够让读者相信它**不是铁板一块**。

| 分区 | 城邦数 | 特征 | 关键设定 |
|---|---|---|---|
| **内圈 · 三强** | **3** | 最早建城，握传送网**主干节点** | 谁坐拥主干，谁就能在联盟里多说一句话 |
| **中环 · 十七邦** | 17 | 商业与学院城 | **学院 / 古武院**（§14.1 第三条路）基本都在这一圈 |
| **外环 · 二十七邦** | 27 | 边城 · 军镇 · 商道节点 | 灵地归属争端 · 兽潮第一线 · **奴隶贸易的口岸** |

**联盟的三条制度事实**
1. **不是帝国，是停战书**（§11）→ 联盟**没有常备军**，只有各邦自己的镇国编制；**战时才推统帅**。
2. **没有神** → **人类是唯一「神位全空」的大族**——这是联盟一切不安全感的根。
3. **城市自治，联盟只管三件事**：**传送网对接 · 联防互保 · 对外议约**。其余各邦各说了算。

**联盟内的三个冲突接口（可直接拿去写戏）**
- **内圈 vs 外环**：主干节点的**票价与配额**——外环边城永远排在后面（§9.1 补）
- **共和 vs 王政**：47 邦里两种政体并存（§14.3），**通婚、弑亲、继承权**三件事没有统一法律
- **守旧 vs 开明**：是否承认**九炉联合体**为同胞——联盟里有人把北邦当叛徒，有人当亲戚

> **「数十城邦」由此变成：47 个各自有理的、没有神的、靠一纸停战书捆在一起的人类政体。**

### 11.1 两个被补上的政体【v7 新增】

#### 🏛 九炉联合体 · 「九炉议会」/「矮人帝国」/ 北邦

> **它不是矮人的国家，是人类与矮人「合」出来的国家。**

- **位置**：主大陆**正北**（灰铁群山及其周边低地）<span class="mark add">位置由我设定</span>
- **成因**：**人类有阵法无锻造，矮人有锻造无法阵**——两族的短板完全互补，于是**正北的人类与矮人结成长期联盟**，最终合并成一个政治体。
- **「九炉议会」由人类与矮人共同建立**，不是一个纯矮人的机构。
- **人口结构**：两族往来过于频繁，且**彼此非常相似**——于是**产生了大量混血种**。
- **身份认同倒置**（这条最要紧）：<b>那一块的人类更认同矮人，不认同人类。</b>他们自视为这个联合体的人，而不是「人类的一员」。
- **多个称号**：**九炉议会**、**矮人帝国**、**北邦**……外人各叫各的——<b>而他们自己其实不太在乎叫什么。</b>
- **它是一块封闭独立的地带**：与中央平原的人类城邦联盟只是名义上的同胞，实际各行其是。

> **这条设定的真正作用**：它打破了「六大种族各自成国」的整齐格局——**世界上存在一个跨种族政体，而且那块地方的人类，不认自己是人类。**

#### ⚖️ 誓约之地 · 公会自治领（五族混居的中央地带）

- **位置**：内海西岸、大陆中央——**正是当年几位半神坐下来开会的地方**，也是冒险者公会的中心。
- **性质**：**由冒险者公会自治**，法律极简，**尊重奴隶制**。
- **五族混居的「大杂烩」**：沿内海的这条巨大脉络上，**兽人、海裔、人类、精灵、矮人**齐聚，各自都有庞大群体——矮人在这一带的居民甚至比在山上还多。
- **两套并存的经济**：**官方拍卖行**（合法、公开、税费齐全）与**庞大复杂的黑市**（违禁品、来路不明的上古遗物、奴隶）**隔着一条街同时运转**。
- **为什么大家都肯来**：因为它**中立**，因为它**不管闲事**，因为**谁都能在这里卖掉不该卖的东西**。

> **于是「中心」这个词有了两重含义：地理上的中心，和道德上的无人区。**
**三条权力命脉**：教会的净化、精灵的治疗、半岛的遗宝与通道——**全都要经过冒险者公会。**

### 11.2 教会教义与异端定义【v10 补 · 附录B #11】

**教义三基（只有三条，其余全是这三条的推论）**
1. **光明印安奉于圣山，且它终将自己选择。** → 教会的正统身份是**守候者**，不是**拥有者**。（**这是对信徒的公开教义**——真相见下）
2. **净「质」不治「形」。** 圣光只让扭曲的以太回归自然（§2.2），**肉要靠精灵** → 教会必须承认**自己有一半是残缺的**，这是一切教内张力的源头。
3. **蚀主已死，但黑暗印还活着。** → **战争没结束**，只是从"打他"变成了"守住封印"。

**核心机密 · 真相（不落文字，教宗口传给继任者）【v15 新增】**

> **圣山没有印。** 光明印在**异次元的封印里**，与黑暗印同处，以光镇暗了三万年——**破晓者归寂的方式，就是把自己的印留进去当锁**。
> **所以教会守的从来不是一枚印，是一道锁；它宣称的圣地，是假的。**
>
> - **为什么不能承认**：印一拿开，封印就开——**它不是选不中，是不能**；
> - **朝圣的真相**：所谓「圣战 · 清剿半岛邪教」，实为**定期渡海加固封印**；而渡海的路要走**公会的发证**——**教会与公会互相握着对方的把柄**；
> - **教内的三层认知**：**教宗**（知情）→ **极少数枢机**（知情）→ **其他人，包括卡西乌斯**（真心信圣山叙事，所以他会天真地主张「指派人选」——**他主张的那件事，在物理上做不到**）；
> - **这个秘密的重量**：每一位新教宗上任的第一件事，是听前任说一句——**「圣山是假的」**。

**「异端」的四级定义**（越往后越重；**而"谁有权判定"本身就是教内争夺的东西**）

| 级 | 名称 | 定义 | 处置 |
|---|---|---|---|
| **Ⅰ** | **偏差** | 对教义的解释与正统不同 | 辩论 · 训诫 |
| **Ⅱ** | **僭越** | **未经遴选而自称承接圣光** | 剥夺教职 |
| **Ⅲ** | **涉暗** | 接触黑暗系 · 佩戴仿印 · 买卖半岛之物 | **交公会发落**——教会自己不动手（这正是"半岛发证权"的另一面） |
| **Ⅳ** | **蚀染** | 体内确有黑暗以太 | **不判，直接净化**；净化失败者 → **公会的净化任务** |

**被蛊惑者能否被救回（伦理核心）**
> **能，但代价不对等，而且制度上几乎做不到。**
> - **圣光**只能把扭曲的以太**推回自然态**，**推不回已经变形的肉**（§2.2）→ 人回来了，形不一定回来。
> - **精灵的修形**能把肉修回去，**但清除不了黑暗以太** → 两者必须**同时、同地、由两族共同执行**。
> - 而**精灵闭林、教会不认精灵的法** → **于是"救一个人"在制度上几乎不可能。**

> **这就是 §2.2 那条"公会的命门"落到实处的样子：不是抽象的"必须经过公会"，是具体到某个村子里那个被咬了的孩子。**

**内鬼怎么查 · 「蚀染检测」【v13 补漏洞】**

> **漏洞**：内鬼名单（六阶 30~50 人、四阶数万倒向半岛）早已存在，**可验印师连伪印真假都分不出（§4.3），那内鬼怎么查？**
> **补法**：**伪印分不出，但黑暗以太本身查得出。**

1. **圣光的「净质」能测蚀染**——长期接触黑暗系，体内会积累**可被圣光激发的暗痕**（见 `01_世界底质.md` §1.2）。
2. **但检测有三个硬限制**：
   - **被测者必须配合、不能反抗**（反抗时暗痕能被压住）；
   - **测一次伤一次元神**——所以**不能普查，只能查重嫌**；
   - **内鬼能「洗」**——用圣光或生命魔法清掉暗痕（正是 §2.2 两大治愈），所以只能抓住**「刚接触过黑暗系」的窗口期**。
3. **于是「审判」变成了一场猫鼠游戏**：教会查、内鬼洗；查得越狠，教会与被诬告者的仇越深。

> **这一条让「内鬼」从设定变成了可操作的剧情**：
> · **伪印**是商业线（验印师）；**蚀染检测**是政治线（审判庭）——两者一明一暗，互不相通。
> · 而最狠的钩子是：**一个被冤枉的人，为了让检测过关，反而真的去投了黑暗侧。**


### 11.3 次级势力 · 每个大势力下面的那一层【v15 新增】

> **用途**：大纲写到「势力」就停了，而剧情发生在这一层——**大势力决定方向，次级势力产生摩擦**。
> **一条通用规矩**：**同一阵营内部的裂缝，永远比阵营之间更好写**（读者天然理解“自己人也有分歧”）。

| 大势力 | 次级势力 | 要什么 | 谁能对谁下令 |
|---|---|---|---|
| **人类城邦联盟** | **内圈三强**（握主干节点） | 票价与配额的定价权 | 内圈可否决外环的联防议案 |
| | **外环二十七邦** | 求救信的优先级、抗兽潮的兵 | 战时推统帅前，外环可以不认 |
| | **共和派 / 王政派** | 政体之争（通婚、弑亲、继承三案） | 各邦自治，联盟只管三件事 |
| | **奴隶商团**（外环口岸） | 货源与航道 | 公会不抓，黑市不管 |
| | **工匠行会残部** | 传送网图纸与复建权 | 公会备案制之下，仍有技术底牌 |
| **圣光圣庭国** | **教宗与守序派**（知情层） | 维持封印与谎言 | 可以调动审判庭 |
| | **狂热十字军派（卡西乌斯）** | 指派人选、武力朝圣 | 只能调动本系统骑士团，**且不知情** |
| | **封印修会（秘密）** | 渡海、加固、封口 | **只听教宗一人**，教内无编制 |
| | **审判庭** | 蚀染检测与异端判定 | 与公会互相移交 |
| | **朝圣团**（半公开） | 名义清剿，实际值班 | **被公会发证拿涅** |
| **冒险者公会** | **总会（赛琳·多恩）** | 中立的存续 | 对分部有调度权，**对执衔无军令权** |
| | **大区分部 / 城市分部** | 本地利益 | 阳奉阴违是常态 |
| | **转运行会系统** | 票务与货引 | 黑市的对家，也是走私的默许者 |
| | **验印师行会** | 伪印市场的话语权 | 行规约束，不受总会直接管辖 |
| | **口信与暗单网** | 地下信息 | 「公会默许存在，但绝不写进册子」 |
| | **私藏 5 件 S 级的保管层** | 谈判桌底的威慑 | **只对总会长一人负责** |
| **精灵族** | **圣林长老议会（主族）** | 闭林政策的延续 | 对外围族群**只有承认权，没有调兵权** |
| | **外围族群与游学商站** | 交易与出林 | 表面听议会，实际自负盈亏 |
| | **黑暗森林族** | 对人类动武 / 接触黑暗以太 | **不听议会**，但**全族仍认生命神** |
| **矮人族** | **九炉各氏族** | 炉位与矿脉 | 九炉议会是合议，**一炉一票** |
| | **人类席（九炉联合体）** | 阵法与商路 | 与矮人席对等，**混血的身份认同偏向矮人** |
| | **下山采购队** | 粮布日用 | 最常被掳，也是最懂外界的一群 |
| **兽人诸部** | **诸部议会**（名号） | 打赢时的旗号 | **有形式，无约束** |
| | **大部落 / 强者** | 草场、水源、奴隶 | **谁打赢听谁的** |
| | **边陲集市派** | 与内海交互区做买卖 | 愿意服从公会票据的那一支 |
| **龙族** | **各龙独立**（无派系） | 各自的巢穴与尊严 | **无组织——这是 canon，不要建制** |
| | **岛内走私者**（少数） | 龙材换私利 | **躲着同族**——龙族最大的丑闻 |
| | **龙涎渡的倒爷**（大陆侧） | 龙货与龙人改造 | 与岛内走私者**隔着海峡分成** |
| **海裔** | **深海城邦**（守秘） | 水神与潮音珠 | 深海不书不传 |
| | **近海海裔口岸** | 盐、铁、航道 | 与陆地通婚最深的一支 |
| | **潮语者（涅拉）** | 水神的传话 | 对深海城邦**有神意背书** |
| **堕落半岛** | **迎印派** | 捞印认主 | 最像军队，**蚀使名义上统辖** |
| | **赎罪派** | 「圣人归来」叙事 | 人数最多，**与迎印派抢同一个人** |
| | **实用派** | 只要力量、不要神 | 不讲信仰，**最难铲除** |
| | **内鬼名单**（大陆侧） | 三派各有一份 | **各派互不知全，甚至互相出卖** |

**三条用法**
1. **先写次级势力，再写大势力**——读者记住的是「审判庭与公会的移交规矩」，不是「圣光圣庭国」。
2. **同阵营内部的裂缝就是免费的剧情引擎**：**卡西乌斯（不知情）想动光明印 ↔ 教宗（知情）必须阻止他**——他越努力，越危险。
3. **下令关系要“卡半口气”**：公会对执衔只有评级没有军令、议会对黑暗森林族只有承认没有调兵、蚀使对三派只有名义——**所有“上级”都差半口气，摩擦才有地方长**。
