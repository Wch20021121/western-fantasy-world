**目录变化**：`site/`（12 个静态文件）→ 整体存档至 **`temp/site_static_v13/`**（工作痕迹，不删）；新工程位于 **`web/`**。

**迁移与验证留痕（均在 `temp/`，按规矩不删）**

| 文件 | 作用 |
|---|---|
| `temp/patch_html2vue.py` | 11 页批量转换脚本，**先 `--dry-run` 后 `--write`**；转换后断言零残留旧链接 |
| `temp/render-check/` | happy-dom 真实挂载验证：**23 项断言全绿**（首屏渲染 / 点击切换 / 往返闭环 / 深链 `/#/races`） |
| `temp/site_static_v13/` | 旧静态站原件 |
| `temp/serve.log` · `temp/serve.pid` | 8000 端口服务的访问日志与进程号 |

**过程中发现并记录的坑**

1. **`meta` 化**：`nav`/`title` 写在路由**顶层**会被 vue-router **静默丢弃**——标题不随页面切换。必须写进 `meta: { ... }`，`check.py` 已加此检查。
2. **vue-router 5.x 只监听 `popstate`，不监听 `hashchange`**（源码里 `hashchange` 计数为 0）：因此**不能用「改 `location.hash`」来驱动导航**，必须点击 `router-link`（内部走 `pushState`）或走首屏深链。校验脚本据此改用真实点击。
3. **`#app` 包裹层安全**：`style.css` 只有 `*` / `html` / `body` 级选择器，无 `body >` 结构选择器，故 `<body>` 下多一层 `#app` 不影响任何布局。
